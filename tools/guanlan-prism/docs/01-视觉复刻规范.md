# 01｜视觉复刻规范

## 优先级

**运行成品 + 源代码是实现标准；本文件解释设计，不授权二次创作。**

同数据、同环境、同状态下，以实际截图对照。数据不同会导致文字换行、图形与数量改变，不应通过裁字、换数据或改变字号来硬凑一张图。

## 设计主张

这是个人研究工作台，不是行情大屏、游戏界面或营销落地页。光场提供空间感；玻璃面板托住事实；主要内容保持清晰、稳定。保留 V1 用户已经认可的总览、清单、星图、时间线、个股复盘与收藏布局。

“酷炫”具体来自六处：顶部程序生成的倾斜光环；细线与半透明底色形成的面板层次；青—蓝—紫的边缘反射；随鼠标位置移动的卡片高光；进入与切换时的轻量运动；明暗两套完整配色。不能只换一个紫色背景就算复刻。

## 色彩

`design-tokens.json` 给出精确变量，源头是 `src/prism.css`。主要暗色值：背景 `#070910`，面板 `#101725`，正文 `#edf3ff`，次级文字 `#a2afc5`，辅助文字 `#7789a3`，主强调 `#91f5df`，上涨 `#ff8b9c`，下跌 `#60d7b2`，蓝色 `#91b5ff`，金色 `#e7bf81`。

涨跌延续红涨绿跌。青色的收盘曲线是“当前选中序列”的识别色，不表示图中所有交易日都上涨。观点支持/减弱/失效也不与单日涨跌混为一谈。

浅色背景 `#edf0f9`，面板近白，正文深蓝，强调转为更深的青色。浅色不是给深色套反色滤镜，顶栏、阴影、图表、弹窗和光环有独立处理。

## 结构与尺寸

桌面保留左侧导航。常规侧栏 228px，1051–1250px 的紧凑桌面为 202px；581–1050px 使用 72px 图标栏。580px 及以下转为 64px 底部导航，并追加 safe-area 空间。

桌面顶栏 74px；主内容常规横向留白 34px；手机顶栏 62px、内容留白 17px。常规总览是可伸缩主图 + 318px 观点栏，间距 20px。大屏和中屏按源码已有断点调整，不固定整张页面宽度为截图宽度。

指标、股票卡片、主图、观点、文章、弹窗使用同一套材质，但圆角与内边距按组件区分，不统一粗暴设成一个值。

必须保留 `base.css`，它承担基础结构与原有断点；再加载 `prism.css`，覆盖 V2 视觉与细化响应式。只拿 prism.css 不能构成完整页面。

## 字体与信息层级

使用系统字体栈，不附带字体文件，也没有在线字体请求。数字、代码和正文分别使用 `--num`、`--mono`、`--sans`。数字使用等宽数字特性，避免切换数值时列对不齐。

常规桌面首页标题 38px，主要收益 48px，指标数字 36px，正文 12–14px。手机有专门字号，不把桌面缩成图片。文章使用较高行距，长报告保留完整阅读，不以固定高度裁掉正文。

macOS、Windows、Linux 上的系统字体字形可能不同。严格截图对照需要同环境；不能承诺跨操作系统每一个字形像素都相同。

## 图表

保留 SVG、真实坐标、原参考价虚线、20%目标虚线、成交额、悬浮提示、时间轴和未来部分隐藏行为。不要为了“更丝滑”把日收盘折线改成会过冲的样条，也不要把 K 线变成概念性的装饰柱。

光环和侧栏轨道都是装饰，不能放进价格坐标系，不能修改股票光点的数据坐标。涨跌为零、缺少参考价、缺少行业线都有不同处理。

## 动效精确要求

| 效果 | 本版实现 |
|---|---|
| 页面进入 | 550ms，`cubic-bezier(.16,1,.3,1)`，10px 上移并淡入 |
| 指标进入 | 650ms；第2–4张延迟45/90/135ms |
| 走势线展开 | 1650ms；不改数据坐标 |
| 主图上缘光带 | 13秒往复 |
| 侧栏轨道 | 22秒轻微旋转与上浮 |
| 光场 | 原生 Canvas；单个 requestAnimationFrame 循环，帧间隔至少32ms，像素比最多1.75 |
| 卡片响应 | 随鼠标局部高光，悬停上移；不把整页大幅倾斜 |
| 用户减少动态 | 所有装饰动画/过渡关闭，Canvas 保留静态一帧 |
| 页面隐藏/光场移出阅读区 | 停止调度装饰 Canvas；重新可见时恢复 |

右上角星光按钮控制装饰；不会关闭用户主动要求的逐日回放。手机粗指针不要求鼠标悬停。保留正常键盘焦点外框，不因截图美观删除无障碍焦点。

## 不得改变的视觉细节

不要换通用后台模板；不要把所有边框加粗或所有组件做高亮霓虹；不要把观点正文画在 Canvas 中；不要让光环遮住标题或按钮；不要移除浅色；不要把搜索弹窗缩成右上角输入框；不要给背景光环附上虚构的评分、实时连接状态或收益数字。
