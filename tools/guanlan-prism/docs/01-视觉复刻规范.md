# PRISM V3 视觉复刻规范

## 视觉基础保持不变

沿用PRISM V2的深蓝黑、青蓝紫光环、玻璃面板、薄边高光和轻量动画。新版本不是换皮。`src/base.css` 管基础布局，`src/prism.css` 管光场材质，`src/v3.css` 管本次六项功能后的尺寸与排列。必须按这个顺序加载；不要合并时丢失覆盖关系。

深色基础：背景#070910，面板#101725，正文#edf3ff，辅助文字#a2afc5，薄荷高光#91f5df，蓝色#91b5ff，紫色#aa9bff。价格上涨为粉红#ff8b9c、下跌为绿色#60d7b2。观点增强/减弱标签是另一种语义，不等同价格涨跌。

浅色保持独立变量组，不做粗暴颜色反转。字体使用系统字体栈；没有附带字体文件，跨平台字形存在正常差异。

## 模块尺寸与自适应

市场卡片默认4列，数量由配置决定；宽度不足1000px改为两列。小图只来自真实日线。缺失卡片保留相同边框和材质，用横杠、缺失标签表达，不能用灰色随机走势装饰。

总览主图区左侧为走势聚焦、右侧为观点更新。1440px下右侧340px，大屏390px；不足1000px上下排列。聚焦原图表、目标线和指示点保留，首字徽章删除。添加当日深读数量及股票选择菜单。

观点更新区按前三条的真实高度计算可见高度，原因文本不省略、不两行截断；其余条目在同一滚动容器内。常驻5px竖向轨道和蓝紫拇指位于右侧，绝不依赖操作系统是否隐藏原生滚动条。

推荐轨道桌面每张宽度=(容器宽度−3×16px)/4，间距16px；不足1000px两张；不足600px一张。卡片底部增加推荐日期。轨道下的常驻横向滚动条为真实range控件，宽度比例随可见范围变化，可拖动/左右按钮/触摸。数据条数不限于四。

表格股票名称直接起头，不补Logo、行业icon或序号块。表格保留横向溢出滚动以适应手机，不压缩数字到不可读。收盘价列标题附本次交易日与“元”。

## 动效保留

`effects.js` 是已有Canvas光环及卡片鼠标高光；仍监听 `guanlan:render`。顶部星光开关关闭装饰，不禁止用户主动回放。系统减少动态效果时静态呈现光场，测试截图固定相位0。

截图是成品实际浏览器渲染，不是AI生成图。对照截图必须同一数据、同一尺寸、相同主题、固定动效相位。不要为“截图一致”更改原数据。
