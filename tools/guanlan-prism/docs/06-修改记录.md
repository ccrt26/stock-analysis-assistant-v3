# 06｜相对用户认可的 V1 改了什么

## 保留

原快照 JSON；确定性展示计算 core.js；页面主结构；总览、记录、星图、时间线、收藏、个股阅读、搜索、导出、回看及原来的数据边界。

src/base.css 原样继承 V1，避免功能布局在视觉升级中漂移。主要视觉变化集中在 src/prism.css。

## V2 新增视觉

深蓝黑与浅色蓝白两套配色；青蓝紫光场；全局克制背景光；玻璃面板与边缘反射；新的品牌矢量锁定；侧栏光学轨道；鼠标局部高光；卡片光泽；主图上缘光带；更明确的文字/数字层级；重新校准手机端细节。

src/effects.js 只做装饰。它不读取股票、价格或研究结果。提供视觉动效开关、系统 reduced-motion 处理、后台/离屏暂停、粗指针限制和测试检查入口。

## 为移植补的最小改动

首页/页脚/说明里的日期和记录数不再写死；新数据没有指定演示对象时，不再因空股票引用报错，而是退回源记录顺序；空快照有明确空状态；正式模式不固定演示股票；app.js 增加一个 `guanlan:render` 事件，供装饰层在导航后同步状态。

这些不是新选股规则，不改变 stocks、参考价、复盘原文或计算公式。默认演示保留原案例顺序。

## 交付结构

增加单文件与拆分版共用的构建器；增加直接接入的 render_html 函数；增加完整交互清单、视觉变量、数据合同、移植说明、实际截图及可复跑验证。

没有新增运行时依赖，没有引入React/Vue/组件库/在线图表库，没有连接网络或修改原仓库。测试依赖与运行依赖严格分开。
