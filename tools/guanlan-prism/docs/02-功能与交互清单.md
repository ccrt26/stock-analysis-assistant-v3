# 02｜功能与交互清单

本版不新增研究结论。下表说明所有已实现路径及源码入口；移植后都应保留。

| 区域 | 用户动作与结果 | 主要源码位置 |
|---|---|---|
| 侧栏/底部导航 | 总览、全部观察、星图、观点时间线、收藏之间切换 | shell.html / `navigate()`、`render()` |
| 首页4张指标 | 观察记录→清单；重点关注→对应筛选；观点调整→时间线；高于参考价→对应筛选 | `overview()` 与 action 分派 |
| 走势聚焦 | 显示一条记录；左右按钮切换聚焦对象；“完整复盘”进入个股 | `heroStocks`、`overview()`、`drawPlot()` |
| 观点变化摘录 | 每条进入对应记录；“全部”进入完整时间线 | `currentChanges()`、`overview()` |
| 观察卡片 | 状态示例/近期记录切换；卡片打开；星标只改收藏不误触打开 | `chooseExamples()`、`card()`、`toggleStar()` |
| 全部观察 | 按重点、调整、高于参考价、待参考价筛选；名称/代码/行业搜索 | `filteredStocks()`、`records()` |
| 排序 | 推荐日期、观察进度、较参考价涨跌升/降序；缺失值不伪装为0 | `tableRows()` 与 sort 分派 |
| 全量导出 | 导出完整快照 JSON | `downloadData(false)` |
| 星图 | 坐标＝观察天数和较参考价涨跌；圆点大小与成交额有关；悬停展示，点击打开 | `drawAtlas()`、`mapSelection()` |
| 时间线 | 按复盘日期切换；只看调整/全部复盘；打开相应历史观察日 | `journal()` |
| 收藏 | 当前浏览器的阅读收藏；与持仓无关 | `toggleStar()`、`state.favorites` |
| 搜索弹窗 | 名称/代码/行业定位；同一代码不同推荐分别展示；上下键选择、回车打开 | `openSearch()`、`searchResults()` |
| 个股指标 | 收盘、较参考价、推荐以来最大回落（收盘口径）、量能较5日均量、现价到目标仍需上涨 | `detail()`、core.js |
| 图表模式 | 收盘走势 / K线+成交额 / 相对表现 | `drawPlot()` |
| 悬停图表 | 对应日期的开高低收、成交额、参考价涨跌；相对模式显示归一值 | `drawPlot()` pointer 事件 |
| 时间轴 | 点击已观察日、拖动滑杆，或聚焦图表后左右键；未来数据隐藏 | `setDay()`、`refreshDetailDay()` |
| 自动回放 | 默认从第一天起逐日；可暂停；到末日停止；切页也停止 | `play()`、`stopPlayback()` |
| 个股正文 | 当日复盘 / 原推荐理由与风险 / 公司资料 | `reviewBody()` |
| 判断过程 | 事件时间线定位观察日；最初判断始终保留 | `detail()` 事件区 |
| 个股导出 | 所选截止之前的价格、复盘、事件；不泄露未来阶段 | `downloadData(true)` |
| 顶栏 | 搜索、专注（隐藏侧栏）、动效、明暗 | app.js / effects.js |
| 说明弹窗 | 数据来源、时间、口径、原文冲突、动效与本地使用说明 | shell.html |

## 必须能复现的具体样例

包内快照中，银龙股份第11天收盘 7.90、原参考价7.19，因此较参考价 +9.87%。回到第一天，较参考价应为 +1.53%，不能沿用末日数据。

“中国船舶”有两条不同推荐日期的记录，原参考价分别34.10、34.80。搜索必须能找到两条，不能合并。

鸿富瀚还未进入首个观察日，没有推荐后涨跌；华昌化工缺少可靠参考价；中航西飞缺少本包可用的行业路径。不能用0、插值或随机线补齐。

这些是对**包内样例数据**的测试，不是新的股票评价。全部断言可在测试文件里看到。

## 空状态与状态保持

无搜索结果显示空状态。没有收藏显示收藏提示。输入空快照显示“暂无观察记录”，不填入演示股票。新数据没有演示对象时，聚焦与卡片退回已有记录顺序，不产生空引用。

主题与收藏跨页面保持；允许的浏览器环境中尝试保存到 localStorage。存储不可用时保留当前会话，不报崩溃。动效开关使用独立键；系统减少动态效果优先。

## 手机注意事项

列表可在自己的表格容器内横向滚动，整页不可横向溢出。底部导航固定在安全区域。图表与观点上下排，时间轴分两排。文章与事件保持可读。不要把 hover 作为唯一的可达路径。

## 快捷键

⌘/Ctrl K 搜索；`/` 搜索；1/2/3/4切换主要页面；Esc关闭弹窗；搜索内上下键与回车；图表获得焦点后左右键逐日回看。输入框打字时不触发页面数字快捷键。
