# 六项规则与交互｜V3权威说明

## 0. 范围与日期

“当天”指 `analysis_date` 的已收盘交易日，不是电脑当前日期，也不是可能更晚的 `as_of`。本示例为2026-09-04。股票身份为 `code + ':' + recDate`，同代码不同推荐独立保存。所有推荐、条件事件和已失效历史沿用输入身份，不在展示层重分推荐等级。

## 1. 市场概览

默认指数为000001.SH上证指数、399001.SZ深证成指、399006.SZ创业板指、000688.SH科创50。`presentation.marketCodes`可选择三至五项；第五项应来自真实研究范围配置，而不是为凑数。

只有 `trade_date == analysis_date` 的数据可以显示当日收盘。日涨跌=(close/previousClose−1)×100；涨跌点数=close−previousClose。若缺前收，保留当日收盘但日涨跌显示空。非当日快照不更新标签日期、也不带入旧值。

原旧快照只有market_name=上证指数及market序列，规则能从对应日期读出上证；没有其他指数则空。只有实际序列才能画小图。市场内容不是按钮，不假装能导航到未实现的行情页。

## 2. 走势聚焦

取当日每条推荐的最新复盘，必须为regular_detail。不使用attention、viewChanged、涨跌幅或示例名字代替类别。checkpoint_detail与brief都不进入。默认上限8只，可在0—8内配置。按上游dailyDeepReview.recordKeys顺序；未提供时按源记录顺序，不宣称这是推荐排名。

同公司多条普通详评合为一个“股票选择项”，内含独立推荐记录选择；不合并参考价和判断。最多8只不同公司，0只就空状态。显式上游名单为空或日期不符时，不擅自恢复旧名单。数据异常超过上限时只显示上限并提示来源总数，不删除源数据。

当日停止主动跟踪但仍有普通详评的记录可进入聚焦，原因需要读；这和表格默认隐藏失效是不同功能。

仓库核对依据：`.agents/skills/reviewing-stock-recommendations/SKILL.md` 的“每日判断与主动跟踪”，2026-09-07通过连接器读取：节点详评不占普通详评8只名额，普通详评由研究流程选择。前端不重复执行该选择。

## 3. 推荐股票清单

记录按recDate降序，同日保留输入顺序。没有只取前4条的代码。初始横向滚动位置0；桌面4卡、平板2卡、手机1卡。股票卡片、左右按钮、拖动横条、触摸均可使用。切换聚焦股票不清空轨道位置。

待首日的卡片收益为空，小图注明首日观察前走势；已有价格不等于已有推荐后成绩。卡片显示推荐日期（formedOn；缺失回退入选日期），条件事件有原类型提示。星标只影响收藏。

“全部N条→”进入包含失效的完整表格，两个范围按钮明确打勾，数量与标题一致。此后点击“全部”按钮会排除失效。

## 4. 观点更新：方向与信心必须分开

本栏目更新的是**未来1—3个交易日的方向判断**，不是当天K线颜色，也不是原推荐支持度。使用同一推荐记录当前交易日最新复盘，与最近一个更早复盘日期比较。上次可能不是紧邻交易日，界面显示实际比较日期。

精确归类：

| 输入base原文 | 方向类别 |
|---|---|
| 未来1—3个交易日更可能震荡偏强 | 上涨 |
| 未来1—3个交易日更可能继续走强 | 上涨 |
| 未来1—3个交易日更可能横盘整理或等待新变化 | 横盘 |
| 未来1—3个交易日更可能震荡偏下 | 下跌 |
| 未来1—3个交易日更可能继续偏弱 | 下跌 |
| 未来1—3个交易日更可能高位剧烈波动并出现回吐 | 下跌（保留原完整描述） |
| 等待事件、无法判断、缺失、未知文案 | 不参加方向比较 |

新接口 `outlookDirection` 可以直接给up/sideways/down/unknown/null，优先于旧文案映射；其语义必须仍是同一时间窗的展望。不允许把描述已发生走势的current_path塞进这个字段。原导出没有current_path，本DEMO没有伪称已得到它。

from与to都可识别且不同才入选。上涨→震荡偏上仍同类不入选。上涨状态中信心增强不入选。下跌→判断失效但仍预期下跌，不作为方向转换；当日失效仍在完整观点调整与失效清单里。首次复盘无前值，不编造从上涨起步。

每卡保留完整viewReason，缺失才用outlookReason，不在展示端改写。点击进入全文。默认前三条高度，纵向滚动可见全部；“全部”进入时间线的方向更新模式。时间线另保留全部观点调整和当日全部复盘。

本示例7条：万兴科技(下跌→横盘)、中航西飞(横盘→上涨)、一拖股份(横盘→下跌)、瑞丰新材(上涨→下跌)、德尔股份(上涨→下跌)、中信银行(横盘→上涨)、银龙股份(横盘→上涨)。瑞丰新材两次均标“观点减弱”，但方向改变，不能漏掉。

## 5. 表格列与标签

股票/代码｜推荐日期｜观察进度｜较参考价涨跌｜当日收盘价｜复盘观点｜操作。显示推荐日期（formedOn）；排序键仍为recDate，两者顺序一致。

当日收盘价直接读本日数组；缺本日值时空，不用前一日价格。待首日记录如有本日历史行情，可以显示该市场价格，但推荐后涨跌仍为空。行业不显示在观点列，详情原行业资料不删除。首字方块在所有页面DOM中删除。

标签：观点增强、观点减弱、维持原判、首次复盘、尚未复盘、判断失效。维持原判断仅做展示同义归一。不是所有待确认状态都伪装为维持原判。

失效来源优先级：上游明确的当前invalidated布尔值 > 最新复盘的判断失效/核心预期被否定 > 无复盘时原stage明确失效。不能根据跌幅、资料不足、暂停或“历史上曾经失效”一概判失效，也不能因后续价格上涨就恢复旧判断。数据本身矛盾留给研究系统处理。

## 6. 筛选状态表

| 状态 | 全部按钮 | 失效按钮 | 当前集合 |
|---|---|---|---|
| default（初次进入） | 虚线默认、未打勾 | 未选 | 所有未失效记录 |
| active（明确点击全部） | 打勾 | 未选 | 所有未失效记录 |
| invalid | 未选 | 打勾 | 仅已失效记录 |
| both | 打勾 | 打勾 | 上面两个集合的并集 |

需要区分“默认范围”和“显式选中”，才能同时实现用户的两种操作：初始直接失效=仅失效；先点击全部再点击失效=包含两类。界面勾选和说明必须不同，不能让相同可见状态产生不可解释的行为。

- 点击全部：任意状态→active，清空其他筛选与搜索，不含失效。
- 点击失效：default→invalid；invalid→default；active→both；both→active。
- 两者已选时“仅看失效”：→invalid，并清除价格/观点过滤。
- 高于参考价：切换价格条件，与当前集合取交集；必须有本日价格与可靠参考价，严格大于0才入选。
- 具体复盘观点：切到active，与价格条件组合；下拉不包含失效。首次和尚未复盘是独立值。
- 搜索：在当前范围内按名称/代码/推荐日期过滤（匹配formedOn与recDate）；排序不改变集合；空结果有重置。

本快照初始24条、仅失效11条、并集35条。所有数字通过函数计算，示例仅供验收。

## 7. 观察星图：同股合并展示（2026-09-07 起）

默认改为**按股票看**：一只股票（完整代码含交易所）一个主点，圆点大小仍为当日成交额压缩比例，不乘入选次数。标题为"每一只股票，一条观察主线。"右上角常驻 `N只股票 · M条入选记录 · Z只有坐标 · K只暂未绘制`（N=Z+K，M可以大于N）；侧栏"全部观察"仍按记录条数计。

主点坐标固定**首次口径**：取该组最早一次独立入选记录，X=该记录首日观察（行动日 recDate）到报告交易日的交易日序号（按 dates 交易日历，第一天记1），Y=报告日真实收盘较该次原参考价的涨跌。三个要素成套使用；之后再次入选只更新次数与明细，绝不替换锚点，不平均两次参考价，也不挑收益更好的一条。输入历史无法证明覆盖完整推荐史，界面一律称"本报告最早记录"，不得声称历史首次；这不是延长任何一次20天观察窗口。X轴副题为"自本报告最早记录的首个观察日起的交易日"。

日期口径边界：明细头、选中面板日期与悬停提示展示 formedOn（推荐形成日，标"推荐日期"）；主图坐标、锚点行（最早入选 recDate）、区间行、点标签、"入选N次"徽标与暂未绘制列表保持行动日/计数口径。两类日期并存是有意设计，不得只改其中一处。

入选次数=本报告包含的独立入选记录数（身份 code:recDate，重复载入与每天复盘不计次），徽标"入选 N 次"常驻，一次入选不显示。条件事件保留原类型：全事件标"入选 N 次 · 条件观察"，混合标"含条件观察"，含未到首日的计划记录标"含1次待首日"，不给计划记录虚构参考价或涨跌。

点击光点或徽标在右侧面板展开该股全部入选明细（移动端位于图下）：首次基准、日期、参考价、报告日收盘；最新一次涨跌单列显示但不替换主图基准；每条明细保留自己的类型、参考价、进度与复盘观点，并按原记录键进入对应那次的完整复盘。悬停/键盘聚焦只作预览，点击/触摸固定选中；各轮失效与有效状态互相独立。

"暂未绘制"列表如实列出无法计算坐标的记录及原因（最早入选缺参考价、报告日无真实收盘、待首日观察、交易日历不足），绝不静默换最新基准、不按0%绘制、不用上一交易日价格冒充。可点击查看原因与明细。

工具栏提供"按股票看 / 按每次入选看"切换。记录视图恢复一次入选一个点：每点用自己那次的日期与参考价，配同一报告日的真实行情，标签带入选日期（跨年用完整日期）；这些点是同一报告日的不同基准，不连成价格轨迹。Y轴按本报告真实数据范围自适应（必含0与全部点，两种模式共用），不再使用固定±12%；星图标签不再有任何按股票名字的特例。名字标签只放在自己的点紧旁（上下最多让一格12px），横向也挤不下时省略该点文字，点本身、悬停提示与点击不受影响；多次入选徽标与选中点优先占位。
