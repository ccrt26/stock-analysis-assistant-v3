# 项目接入步骤｜尽量只改原静态报告生成器

## 已核对与未核对

本次通过GitHub连接器读取了仓库 `.agents/skills/reviewing-stock-recommendations/SKILL.md`，确认regular_detail为最多8只普通详评，checkpoint_detail不占名额。读取日期2026-09-07。

本包不是对生产仓库的已合并补丁；没有读取用户本地事实仓，也没有验证当前GLM修改后的导出程序路径。GLM应定位实际入口，不把某个猜测的路径当作已存在文件。

## 第一步：保持成品可复现

解压后先运行 `python3 tools/build.py`，打开dist中的HTML。然后 `python3 tests/run_all.py`。保留这份构建作为视觉对照。不要先换数据再改UI。

## 第二步：定位本地导出

在实际项目搜索现有HTML导出及旧字段（用项目已有搜索工具）：

```bash
rg -n 'review_kind|regular_detail|checkpoint_detail' src tools ops
rg -n 'market_name|reasonFull|recIndex|const DATA|snapshot' src tools
rg -n 'index_daily|000001.SH|399001.SZ|399006.SZ|000688.SH' src tools
```

目录以实际存在为准。只读取必要生成逻辑及数据接口，不运行真实采集任务、不加载定时任务。

## 第三步：最小接入

把完整前端目录放入项目现有适合静态报告资源的位置。原生成器已经能构造同形状snapshot时，直接调用：

```python
# build.py放入项目后，将此导入替换为真实模块路径。
# 这里演示标准库按文件路径加载，能直接复用而不需要新增服务。
from pathlib import Path
import importlib.util

ui_root = Path('/实际路径/guanlan-prism-v3')
spec = importlib.util.spec_from_file_location('prism_build', ui_root / 'tools/build.py')
build = importlib.util.module_from_spec(spec)
spec.loader.exec_module(build)
html = build.render_html(snapshot)  # snapshot来自原报告生成器
Path('/实际输出路径/monitor-report.html').write_text(html, encoding='utf-8')
```

如果只有旧版HTML而尚未改生成器，可先验证转换，不代替长期接入：

```bash
python3 tools/adapt_snapshot.py --snapshot /实际路径/旧报告.html --out /实际路径/snapshot-v3.json
python3 tools/build.py --data /实际路径/snapshot-v3.json --out /实际路径/新展示.html
```

## 第四步：补市场字段

查现有本地index_daily结果是否包含所配指数、对应交易日及前收。提供已有CSV时：

```bash
python3 tools/adapt_snapshot.py --snapshot /实际路径/旧报告.html --market /实际路径/指数日线.csv --out /实际路径/snapshot-v3.json
```

如果缺少数据或权限，页面保持明确缺失。把“缺哪个指数、哪个日期、现有哪个模块能供数据”反馈用户，不盲目新增新的采集架构。三至五项指数按已有选股市场范围配置，禁止以“没推荐科创股票”推断研究范围必然不包含科创。

## 第五步：保留研究分配

原regular_detail标记已经可用时直接沿用。有单独排序名单时传dailyDeepReview；不要在前端按情绪、涨跌或新规则挑8只。视图只负责展示当前日已被选中的对象。

方向更新用展望字段，不要把current_path（已发生路径）和base（未来方向）混为同一个字段。如果希望未来改成已发生路径转换，应另请用户确认，不能在本轮悄悄替换。

## 第六步：验收并汇报

先同示例数据对照截图，后真实数据确认缺失/停牌/同股多次推荐。运行本包测试，也运行原项目受影响的导出测试。不得只运行本包测试就声称整个股票助手无误。

给用户明确：改了哪些文件，怎样打开，四个市场字段的真实来源，8只名单来自哪里，方向字段如何映射，失效三种组合截图，测试命令与原始结果。保留未接入项，不输出“全部完成”掩盖缺数据。
