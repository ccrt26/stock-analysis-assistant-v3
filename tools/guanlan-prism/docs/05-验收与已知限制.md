# 05｜验收、执行证据与已知限制

## 本次实际执行证据

执行命令和输出保存在 `tests/verification-results.json`；细项在 `tests/browser-results.json`、`tests/prism-browser-results.json`、`tests/adapter-results.json`。这些文件由脚本实际运行产生，不是计划中的预期结果。

检查分组：确定性计算、视觉源文件合同、原有交互、PRISM视觉/动效/响应式、兼容快照替换、关键回归，以及全部观察记录的可用图表状态。

基准快照是35条独立记录。遍历所有可用图表模式应得到103次绘制：待首日与缺少参考价的记录不会强行开启相对模式。详情见 all_records.py 的实际输出。

## 移植后的功能验收

先在相同数据下打开每一页，核对功能清单。重点看：银龙股份的第一天与最后一天数字分别变化；中国船舶两次推荐没有合并；无行业线时显示缺失而非补线；鸿富瀚没有推荐后收益；原文没有重写；导出的历史记录不含未来价格与观点。

再核对空快照、新股票名和数量、页头与页脚日期。V2已为这些常见接入情形加了检查，但不代表已验证用户事实仓内所有其他数据结构。

## 同数据的视觉验收

用相同浏览器与系统字体、相同数据、相同记录和观察日。关闭装饰动效或启用 reduced motion，确保不会把不同动画帧当成样式误差。保留键盘焦点样式，但拍基准图前取消上一步操作遗留的焦点。

`tests/capture.py` 可生成整套参考。主要基准：桌面1440px宽、手机版390×844；deviceScaleFactor=1。完整首页截图可能高于1100px，实际图片尺寸以 `previews/screenshot-manifest.json` 为准。

逐项核对：导航宽度、页头位置、四张指标、左右栏比例、卡片顺序、图表位置、日期和收益、光环位置、面板反射、文字行距、弹窗样式、浅色，以及手机底部导航。不要给全页套 screenshot 当背景来通过验收。

颜色、边框、留白、组件排列和数值必须保持。跨系统的细微字形光栅差异不等于产品设计差异；超出字形差异的偏移不能用这个理由忽略。

## 动效验收

默认动态模式下，光场实际持续绘制，鼠标高光随位置变化，卡片和光带有运动；点击星光按钮后全部装饰停止。主动点击“回放观察过程”仍然逐日推进。减少动态效果开启时，光场保留一帧而不持续运动；后台页和滚动离开光场区域停止装饰循环。

不要求浏览器保持某个理论帧率，更不能把样例的渲染感受当成用户手机实测性能。代码只是设置帧间隔和像素比上限。本包没有宣称在用户设备上达到固定FPS。

## 已知限制，必须保留诚实说明

1. **没有接入正式后端。** 交付的是前端成品与适配入口，没有访问用户本地行情仓、没有测试用户的定时生成任务、没有修改仓库。
2. **实际验证环境是 Chromium。** 受管理浏览器禁止 file:// 导航，本次以完整HTML装入页面验证；拆分版也通过装入相同本地源码验证内容与样式一致。没有冒充完成“Mac上双击打开”“真实文件加载”“跨刷新localStorage持久化”或 Safari/华为手机实机测试。可在本机运行 `python3 tests/prism_browser_test.py --file` 补验前两项与存储。
3. **快照不是实时行情。** 原日期和来源保持，不把打开时间标为数据时间，不把装饰性光点标为网络已连接。
4. **原报告本身未由本次前端任务重新核验。** 价格数组、原文、结构化字段可能冲突；图表按数组，正文保留。
5. **演示数据范围有限。** 当前主观察窗口、星图范围与同年日期轴的生产适配边界见 docs/03。移植者必须针对真实超范围情况补最小适配和测试，而不是默认样例等于所有业务均已覆盖。
6. **字体是系统字体。** 不附带字体资源，跨系统可能存在字形和细微换行差异。同环境验收才能做严格视觉比较。

## GLM5.3应回报什么

“做完了”必须附实际运行路径、生成入口、修改文件、测试输出和效果图。无法测试的设备/浏览器单列；有视觉差异逐项说明，不写成“已优化”。用户没有授权的仓库推送或任务调度变更不要做。
