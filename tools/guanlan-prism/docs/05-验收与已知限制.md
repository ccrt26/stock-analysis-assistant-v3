# 验收与已知限制

## 测试入口（本仓库实际存在的命令，在仓库根目录执行）

```bash
# 回归入口：验收脚本自身负对照、日期/日历/枚举/身份合同、构建合同（T01—T51）
.venv/bin/python -m pytest -q tests/test_prism_web_contract.py

# 既有渲染器 / 适配器 / 星图规则测试
.venv/bin/python -m pytest -q tests/test_render_prism_web.py \
  tests/test_render_monitor_web.py tests/test_prism_atlas.py

# 浏览器验收（需要 Node.js 与 Playwright Chromium）
.venv/bin/python tests/check_prism_web_browser.py --out /tmp/prism-web-shots
.venv/bin/python tests/check_prism_atlas_browser.py \
  --html local_archive/forward_monitor/prism-report-2026-09-07.html --out /tmp/prism-atlas-shots
```

- 两个浏览器验收入口把桌面/手机/合成页的全部断言失败与 JS/控制台错误统一汇总，任何失败都以非零码退出，摘要报告实际执行数与失败数；`--browser-executable` 可显式指定浏览器，缺省用已安装的 Playwright Chromium，缺依赖明确退出码 2。
- 真实报告验收的期望值由 Python 从页面内嵌快照独立计算（与页面 JS 同合同、两套实现）；固定数字断言只存在于明确标注的合成回归样本（`synth_main()` 等 fixture），不冒充任意生产报告检查。
- 旧的 `tests/run_all.py`、`tests/capture.py` 不在本仓库中，不要再引用；固定样本计数只属于明确 fixture 的描述，不能作为任意新日报的验收标准。

## 本轮范围与已验证行为

- 市场卡 3–5 项；缺当日报价不造数；当日普通详评聚焦最多 8 只，节点详评与简评不占名额。
- 推荐清单全部 N 条横向滚动可达；无关键词搜索 8 条为建议上限，有关键词时完整结果可滚动/键盘/点击打开（含第 36 条与末条）。
- 方向更新走结构化枚举（outlookDirection/outlookCode），旧快照按精确中文映射；未知枚举显示"未识别状态"，不猜方向。
- 交易日历取本地 SSE trade_calendar；缺行情日保留 null；日历覆盖不足明确失败；首日缺失不取第 0 日顶替；缺价格路径显示"价格数据缺失"，不冒充停牌。
- D0 去重键为 (完整代码, action_date)；同股再次入选两次都保留。
- 快照日期无法定位（跨年旧 MM-DD 等）时页面拒绝显示并提示重建，不猜年份。
- 单文件与拆分构建共用同一资产清单与单遍模板替换；非有限数值在构建期报错。

## 限制必须如实保留

1. 浏览器自动化仅覆盖 Chromium（Playwright Chromium / 可显式指定的可执行文件）。未测 Safari、华为 Mate X6、HarmonyOS 或实机触控性能；已检查 390、768、1024、1440 视口布局，这不等于各设备实测。
2. 星图密集数据下名称标签放不下时按既有规则省略文字（点、徽标与悬停提示保留）；本轮不引入新的标签排版引擎，密集徽标布局仍是已知风险。
3. app.js 仍是单文件大模块、三份 CSS（base/prism/v3）继续叠加；本轮只做功能修复，不做组件化或 CSS 重排（F14 留待后续）。
4. `design-tokens.json` 是文档参考，不是自动生效的运行配置；没有为此另建设计配置引擎。
5. 收藏/主题使用浏览器 localStorage，禁止存储时降级为当前会话；跨会话持久化应在真实文件或站点来源下再测。
6. 页面使用的指数名称表（INDEX_META）是显示元数据；正式管线的市场名单来自 adapt_snapshot.DEFAULT_CODES 并由输入传入。归档校验、渲染锁、原子写入、防旧页覆盖新页与 --no-publish 行为保留。
7. 没有接入券商、没有自动交易、不承诺收益；本页面只读展示本地冻结归档，不重新判断研究方向。
