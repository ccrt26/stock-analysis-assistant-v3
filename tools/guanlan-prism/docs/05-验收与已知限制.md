# A2 主用验收与已知限制

当前入口与命令见 `../README.md`。本页以 A2 主用为准，旧版 Prism 保留为停更备用。

验收覆盖主用与日期页、备用零写入、无备用依赖、正式归档严格日期/截止/覆盖校验、空名单、价量冲突失败、原子替换与旧日期保护；覆盖完整复盘和原推荐原文、公司资料、历史日期、收藏/搜索/星图、40/20/50 日图表窗口、成交量/额、指数弹窗和手机布局。

源码测试使用临时数据，实际页面的股票和更新数量按内嵌快照计算，不写死日期或个股名单。浏览器发现脚本异常、断言失败或缺少必需浏览器时必须返回失败；截图使用本次实际页面。

限制：本地静态页面，不接实时行情。历史查看是在当前已冻结数据上按日截断，不表示重新取得旧时点快照；原报告正文可能包含原有措辞或数字不一致，展示层不代写修订。公司介绍缺项按实际说明；收藏仅保存在本浏览器。备用版停更，重新启用须另行恢复同步，不能当成最新结果。
