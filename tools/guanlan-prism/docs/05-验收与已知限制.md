# 验收与已知限制

## 测试入口

`python3 tests/run_all.py`：重新构建、JavaScript单测、Python适配测试、浏览器测试、构建/静态检查。真实原始输出与JSON汇总存于tests/。不要用旧包测试统计替代移植后的实际执行。

`python3 tests/capture.py`：从单文件实际生成对照截图，固定光效相位与减少动态效果。截图尺寸、浏览器版本由previews/screenshot-manifest.json记录。

## 本包重点检查

- 首页仅指数卡，不再显示旧四项统计；缺三项指数不造数；支持3/4/5项布局。
- 当日regular_detail八只可全部切换，无当日详评则空；普通与节点详评不混用。
- 推荐35条均在横向轨道内，初始桌面恰好4张；横条/箭头/手机/末条可达。
- 七条方向变化，前三条完整原因，竖条可鼠标拖动、键盘操作；后四条没有被CSS隐藏。
- 同股两次推荐独立；首字块在全部页面无DOM；所有可用图表逐条绘制不含NaN/Infinity。
- 表格当日收盘与价格数组一致；本日缺行情不回填；行业从观点列移除。
- default24、invalid11、both35，勾选说明一致；上方全部N条入口打开完整数量。
- 搜索、排序、观点筛选、收藏、时间线、K线、相对表现、回放、导出、主题及手机布局保留。

## 限制必须如实保留

1. 只有上证指数真实输入，其余三个指数接口准备好但缺本地数据。没有行情补齐的生产验收证据。
2. 示例原数据可能在正文、价格和字段间有不一致。本次不复核原研究结论，不静默修正。图表从价格数组计算，正文原样。
3. 当前方向更新是原复盘未来1—3日展望的三类转换，并非即时实盘趋势判断。缺字段不猜；首次记录不计转换。
4. 原日期数组采用同年MM-DD。跨年生产输入需按原系统日期规则完整适配和新增测试。
5. 浏览器自动化使用本环境Chromium，将完整HTML直接装入页面。该环境管理员策略阻止file://导航，因此没有在本环境完成双击本地文件路径的实测；成品结构不依赖网络或fetch。用户应在Mac实际浏览器再打开验证。
6. 未做Safari、华为Mate X6、HarmonyOS或实机触控性能测试。已检查390、768、1024、1440、1920px布局；这不等于各设备实测。
7. set_content环境下存储可能被浏览器禁止；源码保留降级支持。收藏/主题跨会话持久化应在用户真实文件或站点来源下再测。
8. 使用系统字体，无字体文件随包。跨系统不承诺字形逐像素一致；同数据同环境的布局、配色和行为必须一致。
9. 没有接入券商、没有自动交易，没有改GitHub仓库、定时任务或研究流程。生产移植后仍须跑原项目受影响测试。
