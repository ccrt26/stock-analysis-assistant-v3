# 普通详评：用户认可的改稿对照

进入普通详评写作时读取。以下是用户于2026年9月7日认可的教学范例，帮助理解既有四项要求；不是新的分析框架，不提供其他股票或其他日期的事实。节点继续按银龙范例完成阶段对账。

## 杭氧定稿：为何今天必须告知

杭氧股份｜今日触发预设下调条件，短期判断由震荡偏上转为震荡偏下

今天需要单独提醒：杭氧收于26.64元，跌回上次明确写下的26.66元收盘观察位以下；成交由上一交易日6.61亿元降至5.72亿元，出现了预设的缩量回落情形。因此，上次维持震荡偏上的判断需要下调为震荡偏下。继续主动跟踪，但当前价格表现已明显弱于原先预期。

这次调整有事先约定的依据。上次看好回落能够结束，是因为9月3日放量收复到27.67元；随后两个交易日却把这次修复全部交回。今天沪深300涨0.59%，杭氧反而跌2.38%，也使这次回落更难用市场共同下跌来解释。值得重视的，不是比观察位低了两分钱，而是此前支撑乐观判断的修复成果已经失去。原来“回落后仍能继续推进”的期待，受到新的反证。

半年报增长的原有支持仍保留，尚无依据宣布原推荐全部失败；但也不能继续用经营增长抵消已经发生的价格转弱。

到31.81元观察目标仍需上涨约19.4%，剩14个交易日，必须重新形成能保住涨幅的上行，目标才有可能接近。后续收复27.29元并连续收高，会成为修正本次下调的新依据；仅再出现一天放量反弹，还不足以恢复上次的乐观评价。

## 改的是什么

旧稿已经能说“回落后能收回来，这一次没有维持住”，也覆盖量能、财务和余程，但没有先交代今天触发了上次明写的下调条件。用户因此看到了一篇缩短的阶段复盘，仍不知道今天为何需要单独提醒。

定稿先给具体告知，再用“上次约定—今日事实—评价调整”解释这次下调为什么有据。成交用于核对缩量条件，市场对比用于限制共同下跌的解释，财务只用于划清价格转弱与原推荐完全失败的界线。这些事实没有各自占一个必写栏目。

这里的26.66元是9月2日的收盘观察位。重点是修复成果失去，不能把低两分钱本身包装成确定机制。结尾说明恢复乐观判断需要什么，也说明一天反弹还不够；该句只在本例证据下成立，不要求每篇模仿句式或相同段落顺序。

## 中钢边界：不能为了模仿而伪称触发

用户认可标题：中钢国际｜尚未跌破预设观察位，但收盘持续下移，短期判断由整理转为震荡偏下

本例上轮写“跌破5.35元，降为偏弱”，当日收盘5.42元，这个条件尚未满足。可以依据5.51、5.46、5.46、5.43、5.42元的收盘序列，以及市场反弹时成交恢复而股价仍收低，说明为什么提前调整短期判断；不能改写为“触发5.35元条件”。

同样，条件要求“放量收复某价位”，成交增加但收盘没收复，只能说部分满足。上轮未写过的条件不能事后补成预设。先读上轮正文中的原话，再用当前事实核对；标题并不代替这一步。

## 轮换无新增：如实说明例行复查

没有重大变化、仅因长时间未详评而轮换时，标题应说明例行复查和原判断当前的状态，不制造“今日触发”。正文按已有四项核对原判断仍由什么支持、哪一环还缺证据，余程与障碍照实交代。确实没有新增可对就直说，不把普通波动包装成必须改判的事件。

## 首篇实查怎样留下有用记录

按运行 Prompt 先完成当天第一篇普通详评，再检查标题的告知是否有事实支持、原条件是否被准确引用、四项是否实质回答、外层是否重复。运行过程简短记录核对的具体事实及是否修改，例如本例可说明“已核对上轮26.66元观察位与本次收盘、成交，完整触发；补入同日市场对比”。不能只写“已校准／已通过”，也不输出推理草稿或把这条执行记录加入公开股票报告。
