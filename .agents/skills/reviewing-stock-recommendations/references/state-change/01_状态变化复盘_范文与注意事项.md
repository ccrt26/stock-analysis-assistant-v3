# 状态变化复盘：范文与注意事项

> 本文件所有公司名、价格和情景均为虚构教学，不是实际投资分析，也不是已经验证的选股规则。没有真实股票代码和公告链接，不得进入正式研究事实。

## 示例背景（供作者理解，不放入每日正文）

示例甲的原参考价为10元，原观察期20个交易日，原目标12元。推荐理由是所属行业共同走强、个股持续领先同行并连续收高。原研究已明确：连续两个交易日收盘低于9.60元，就撤回本次上涨判断。所有价位使用同一复权尺度，假设没有公司行动调整。9.60元仅为本例预先给定条件，不是通用止损方法。

下面三个变化案例是独立情景或不同的后续分支，不构成一条必须按顺序发生的真实历史。

## 范文一：继续关注 → 等待变化

### 示例甲｜改为等待变化：同行仍在涨，它却开始掉队

今天把示例甲从“继续关注”改为“等待变化”。原来选择它，是因为行业上涨时它表现得更强；但最近三个交易日，收盘价从10.32元退到10.15元，同期行业仍上涨约3%。原本支持推荐的领先表现已经减弱，我暂时不再按此前的强势延续来期待。

现在还不需要结束跟踪。收盘仍高于原先的9.60元观察位置，也没有触发连续两日跌破的撤回条件。接下来主要看它能否重新跟上同行、恢复向上推进；若做不到，或原撤回条件得到确认，就不能继续沿用原来的上涨判断。

**本例事实**：三个交易日收盘10.32、10.18、10.15元；同窗口行业收益约3%；本例假设没有其他足以改变判断的新公司事实。正文未把“没有新事实”写成实际已核验某家公司全部公告。

**为什么这样写**：先交代意见变化；用“同行上涨而它走弱”解释原推荐中哪一项支持减弱；说明为什么等待而非直接结束；最后给下一观察点。不再复述主营业务、过去所有涨幅或完整财报。

## 范文二：等待变化 → 继续关注

### 示例甲｜恢复继续关注：前面失去的相对强势正在回来

把示例甲由“等待变化”恢复为“继续关注”。此前等待的是它能否重新跟上行业，现在连续两日收盘升至10.30元、10.56元，同期行业只上涨约1%。这次不只是随行业反弹，前面减弱的领先表现也在恢复。

我因此重新保留向原目标推进的判断。原观察期和12元目标都不变，也不把这两天上涨当作一定能到目标。后续仍看收盘能否继续保持，原来连续两日低于9.60元的撤回条件不放松。

**本例事实**：起点收盘10.15元，随后两日10.30、10.56元；相同两日行业约+1%。这里“两日”描述已经发生的事实，不是新设“所有股票涨两天必转好”的规则。

## 范文三：等待变化 → 结束跟踪

### 示例甲｜结束跟踪：原先约定的撤回条件已触发

结束对这次推荐的跟踪。此前等待的是股价能否重新走强，但最近两日分别收于9.55元和9.42元，已满足原研究“连续两日收盘低于9.60元”的撤回条件。最近的变化已经超出当初允许的整理范围，我不再按原来的上涨判断等待12元目标。

这不是说公司以后不会再涨，而是这次推荐所依赖的走势已经被否定。后续不再每日写这条推荐的复盘，原20日结果仍会记录；以后重新出现机会，应按新的事实重新判断。

## 正常到期的短说明

### 示例甲｜结束跟踪：本次观察期已结束

本次20个交易日观察结束。期间按原口径已经达到上涨20%的目标，期末相对原参考价上涨16%，结果已归档。此次结束是观察期正常完成，不是今天突然转为看空。

**仅为示例设定**：原参考价与本例评价入口价均为10元，期内有效最高价12.20元，期末11.60元，没有分红除权。真实任务使用原系统已确定的目标和绩效口径，不能照搬本例价位。

## 注意事项

1. 转态必须来自新的有效事实或对累计变化的真实判断，不为了写长一点而先改标签。小幅涨跌不自动转态，也没有统一的技术天数门槛。
2. 说明为什么改，也要让读者理解为什么改到这个状态：证据只是削弱就不要说已经失败；原条件已确认触发就不要只写“暂时有一点担心”。
3. 引用原条件时保留连续天数、AND/OR、收盘或盘中、复权尺度。原条件含糊时不能临时编成明确条件后宣布触发。
4. 已经达标、正常到期、原判断失效是不同事情；结束原因要写准确。不能把未达目标自动记为原逻辑证伪。
5. 展望给有依据的主判断与最重要观察点，不穷举所有未来情景，也不说“不可能再涨”。原目标不是价格走弱后仍坚持的理由。
6. 有不同推荐日期时说清是结束哪一次，不把旧记录的失效套到同股新推荐。已结束的旧记录不因反弹自动复活。
7. 数字与证据由真实研究提供；这份教学不产生任何新买卖规则。篇幅随解释需要决定，没有最低字数。
