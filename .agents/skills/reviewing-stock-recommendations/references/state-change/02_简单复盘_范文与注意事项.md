# 简单复盘参考：说明为什么继续，而不只报状态

## 范文

### 百亚股份｜强势仍在，但现在不追涨

继续关注，但不在现在追涨。今天收在22元，再创近期收盘新高，近五日比同行多涨12.30个百分点。这说明它不只是随行业普涨，自己的强势也还在，原来的上涨判断仍有支持。

需要接受的代价是，五天已经涨了21.01%，原观察目标也已提前达到。此时再买，等于在一段急涨后承担回落风险，所以我更愿意等它整理后能否收稳。接下来仍看强势能否保持，不上调目标，也不提前结束原观察期。

## 这篇为什么这样写

第一段直接回答为什么仍然跟踪：不只是涨了，而且继续领先同行。第二段解释看似矛盾的两件事：原推荐还值得跟踪，不等于现在适合新买入。已付出的涨幅解释了为什么不追，最后把后续观察点落在整理后能否收稳。

没有重写公司介绍、全部财报或最初所有理由；也没有把“登记为继续关注、当前等待、方向偏上”堆在一起。它比一行状态更长，但多出来的内容都在帮助读者理解。

这不是要求所有简评都分两段，或都加一句“不追涨”。真没有价格代价问题，就不要复制这部分；原研究要求已经触发的撤回、出现的新公告或其他重要反证，必须按该股实际内容说明。

## 来源及使用边界

本文只根据用户提供的9月22日正式报告“百亚股份（003006.SZ）”段落编辑：收盘22元、近五日上涨21.01%、领先同行12.30个百分点、原目标提前达到、当前等待新高后整理收稳。未重新核验原行情或推断用户持仓。

9月22日是新三态的首次登记。本文不声称昨天已登记同一状态，也不把它算作一次状态变化。原正式稿保留，本文只放入参考知识库；后续真实文章必须读取自己的原研究与当日事实。

“整理后收稳”是来源已有的观察方向，不是本例新增可自动执行的入场规则。没有给出新的买价或止损线，也不能据此得出下一天必然上涨。
