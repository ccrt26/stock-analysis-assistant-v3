# 状态跟踪复盘：把变化对判断的影响讲清楚

复盘回答的是：这次推荐还是否值得按原来的理由继续跟踪，今天的事实为什么支持这个看法，接下来主要看什么。不要写成一串行情数字和内部标签，也不要重新写完整推荐报告。

## 方法保持不变

继续关注：原上涨判断仍有事实支持，不保证上涨，不自动等于现在可以买。

等待变化：出现了有意义的新疑点，但还不足以否定原判断，必须说清等待什么。原来已知且接受的风险，没有变化时不能冒充今天的新反证。

结束跟踪：原判断失效、原条件确实无法执行，或观察期正常完成，分别记录原因。不是卖出指令，不说以后绝不可能上涨。已经停止者只补内部结案，不重新生成公开日评。

状态未变写简单复盘，真实状态改变说明原因；首次登记不伪造昨天的三态。节点及第20日结果留内部，不能因为到节点就强写长文。跟踪态度和当前是否适合新买入分开；两者不同而可能使读者困惑时，用一句自然的话解释。

## 写作的重点

先说清当前意见，再用本股最重要的事实解释为什么。数字后面要有它对当前判断的意义；但不要求每个数字都跟一条解释，不按四个专业视角逐项汇报。

简单复盘是一段小分析，不是电报。只处理今天最重要的问题，把事实、含义和下一步自然连起来；必要时分成两个短段落。没有最低字数或固定句式，不为压缩字数省掉理解所需的关系。通常一个主要事实已经够用；重要反证、已经触发的条件不能漏。

状态变化说明要让人读懂：原来凭什么这样看，哪项事实改变了原依据，为什么现在只是等待或已经需要结束，之后怎样重新判断。这是思考问题，不是必须四段或四个小标题。

过程信息如“首次登记”“三条记录统一”“本字段保持”，通常留在内部。读者需要的是本股的看法，不是系统怎么入库。不要只把“当前回避、方向向上、状态等待”并列给读者自己解释。准确说明它们的区别，或只写当前真正需要知道的内容。

必须保持事实与研究含义：不编新订单、资金身份或阈值；不把条件的同时满足改成任一满足；没有依据就不把未来说成确定。资料缺失要说明影响和旧判断日期，不复制昨天改日期冒充今天已核对。公开短文可以选择必要证据，原条件仍完整留在内部并得到实际检查。
