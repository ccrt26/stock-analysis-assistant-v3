# 状态跟踪复盘：阅读与写作指南

每天回答的是：这次推荐是否还按原来的理由发展，接下来怎么看，是否继续跟踪。不是重新写一次推荐报告。

## 先确定意见，再决定写多少

继续关注：原上涨判断仍有事实支持，继续以原目标和期限观察，不保证上涨，不自动等于现在可以买。

等待变化：出现了有意义的新疑点，但还不足以否定原判断。把等待的具体进展说清，不用“继续观察”代替答案。

结束跟踪：原上涨判断已失效，或者原观察期正常完成。说明是哪一种原因，不说以后绝不可能涨，不把结束跟踪当成卖出指令。

状态不变，写简单复盘；真实状态改变，写变化说明。关键节点只作内部对账，不自动多写文章。不为得到详述名额改变标签，也不因没有名额漏掉变化。

## 简单复盘

在一个短段落里说清：今天最重要的进展为什么没有改变状态，下一步主要看什么。一两个有效事实通常足够；没有必要每天重复全部数字、公司介绍、旧财报和最初的推荐理由。

“没有变化”也要有实际检查。资料没有取得就说明缺什么，不能复制昨日文字、改成今天日期，假装完成复盘。状态不变但有新的重要风险或参与意见调整，仍应直接写出，不藏在旧观点后面。

例子见 [02_简单复盘_范文与注意事项](02_简单复盘_范文与注意事项.md)。

## 状态变化说明

先让读者知道由什么改为什么，接着解释改变判断的事实怎样影响原推荐，再说明为什么只是等待或为什么需要结束，以及接下来怎么看。

这是理解顺序，不是强制四段。证据充分且问题简单时几句话也可以说清。正常到期用简明完成说明，不强写成下跌反转故事。

例子见 [01_状态变化复盘_范文与注意事项](01_状态变化复盘_范文与注意事项.md)。

## 表达和证据

说“这两天收盘跌回原观察位置”，不要说“价格支持链进入失效阶段”。数字用来解释判断，别为了显得精确罗列分位数、波幅倍数和计算公式。

几个事实证明同一件事时合并。已经解释过的风险，在下一观察点中可以简短提及，不再把来龙去脉重讲一遍。反证要说明怎样影响当前判断，不在利好和风险列表后只接一句“仍然看好”。

股价上涨不证明订单兑现，下跌不证明公司基本面恶化。原稿的条件、时间、比较对象和确定程度不能因简化而变化。没有原数据就不自造支撑位、连续天数、公告或交易结果。

标题表达中心意见，正文不重复同样的标签串。正文已经讲清的信息，外层不再完整重复一遍。状态和截止日期来自真实本次判断，不用模板自动生成投资结论。

## 使用范围

本目录范文均为明确标记的虚构教学，不是用户已经认可的真实荐股记录。只学习表达和取舍，不复制其数字、期限、价格条件或结论；真实业务以本股原研究为准。

本方法不授权每天改选股Skill。节点记录和结束后结果留给以后独立的批量方法复核；缺数据与判断错误分开，失败样本也保留。
