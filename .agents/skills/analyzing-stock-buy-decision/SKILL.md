# 单股买入决策（尚未买入）

## 0. 这项能力是什么、不是什么

这是一个按需运行的单股买入研究流程：用户指定一只**尚未买入**的 A 股，以本次实际可能买到的价格，判断是否值得参与、为何可能较快获利、什么条件下买、什么情况下放弃，以及买后如何重新判断。

它**不是**：正式每日选股、原推荐评价、正式复盘、自动交易、仓位决定、收益承诺。它不进入 Forward CSV、正式报告模型或任何冻结历史。原推荐的 20% 目标和原观察期只作背景，**不是**新买入的收益门槛或期限。
与日常复盘的衔接：每日复盘的“当前参与意见”（consider/wait/avoid/insufficient）只是当日的粗粒度观察，不构成本项完整研究的触发或结论；用户实际准备买入、需要精确成交时点/价格范围/失效与买后应对时，才调用本流程做完整单股研究，两者不相互替代。

三样起点必须分开：

| 对象 | 用途 |
| --- | --- |
| 原推荐 | 只读引用：当初为什么选、如今发生了什么变化。没有原推荐也可以研究。 |
| 本次拟买入 | 本次分析截止时点、实际可能买到的价格、用户期望的时间窗口。独立计算，不套旧口径。 |
| 真实持仓 | 本次不创建。假设价格不得登记为成交。 |

旧推荐的 `target_price`、剩余到目标收益、剩余观察天数一律不得作为新买入的门槛或卖出条件。

## 1. 先判断问题与材料是否匹配

开始前明确五件事，缺一项就在报告里写明它如何限制结论：

1. 股票身份与可交易性：代码、名称、是否属于可研究范围（沪深主板、创业板；排除科创板、北交所、场内基金、ST/*ST、停牌等）。程序在 `context.json` 的 `identity` 中给出范围检查。
2. 尚未买入：`position_status` 必须是 not_bought。用户拿着持仓来问，不属于本流程。
3. 本次截止时点（`as_of`）：所有事实、日线、公告都以它为准。研究开始后取得的新快照不能混进旧报告；要改截止时点就建新 run。
4. 时间期望：用户约多少个交易日内希望看到获利机会（试点约十天）。这是重新判断的时间参照，不是必赚期限，也不是强制卖出日。
5. 参考买价来源：用户手价（标为用户输入）或最近收盘（标为条件参照）。没有可靠实时报价时，只能给"以最近收盘为参照的条件方案"，**不能声称可以按某价立即买入**。

完整日线与盘中快照分开呈现，两者都是独立时点样本。

## 2. 这家公司和这只股票现在分别怎样

公司部分只保留会改变本次短线判断的内容：主要经营变化、利润来源、现金回收、负债、重要风险与重要公告。利润改善不能自动推出下周股价上涨；订单总金额不能直接当成本期收入或利润。重要事件分开记录：首次公开时间、后续增量披露、首次可观察交易反应、未来已确定事件时间。旧利好不重新包装为新利好；窗口之外的事件不能冒充窗口之内的催化。

股票部分看真实价格路径：绝对与相对（市场/合适行业口径，写明口径）表现、多日推进还是单日脉冲、成交是否推动有效收盘、回落是否破坏走势。不从量价推断"主力""机构"等账户身份。按问题参考本地知识条目的适用边界（含已知失败或禁止用途）；晚几天买入不属于原选股样本已验证的范围。

## 3. 单独回答：为什么可能在接下来约十个交易日获利

区分四类并用实际事实说明，不混在一起：

1. 有新的、时间上相关的变化（公告、事件、行业变化，且落在窗口内）；
2. 已有信息仍在持续被价格反映（披露后的再定价过程还在进行）；
3. 趋势本身持续推进，但缺少可识别的新催化；
4. 没有足够短期推进证据。

没有新公告不等于不能买；长期经营改善不能冒充十天内的上涨依据。写清"可能延续上涨"与"有证据支持很快加速"的区别。没有可靠概率时，不编造胜率或数学期望。

事件的经济相关性由 AI 判断，事件前后收益等计算交给程序，不反向遍历事件收益挑最大者解释上涨。

## 4. 公平比较：现在买、等回落、等突破、不做

报告要有明确首选意见和最有意义的备选条件，不要求为每个动作编出可交易计划。

- **现在买**：从当前可取得、注明时间的参考价格出发，说明支持与代价。
- **等回落**：价格更低不是充分理由；要判断回落是普通波动还是趋势转弱。便宜本身不是确认。
- **等突破**：价格更高不必然更差；突破改变结构时，重新评估突破后的失效位置与下一段路径，不沿用回落方案的止损位和旧高点上限。历史高点首先是"前方需要观察的位置"，不是必然目标或无法突破的天花板；突破后更高的空间必须有依据，没有依据就保持未知，不上调目标价美化盈亏比。
- **不做**：可能因为证据薄弱、机会不匹配时间要求、价格不合适或执行条件不清楚。不能一律用"不到20%"解释，也不能一律说"可以买"。

不足20%的机会可以被支持；超过20%的想象空间也可能因证据不实而被拒绝。

## 5. 参与条件必须写成现实中能观察、能判断的方案

每个被称为可执行的主要参与方案，六项缺一不可：

1. 依据什么可观察信号，**信号在什么时候才真正知道**；
2. 信号知道以后，最早在哪个允许且实际可用的交易时段考虑参与；
3. 那个时段仍可接受的价格范围或上限，以及研究依据；
4. 高开越过上限、没有回落、涨跌停或无法成交时怎么办（价格跳过计划区间后不得照抄旧盈亏计算）；
5. 什么时间或出现什么新事实后，旧方案作废；
6. 哪个条件推翻买入判断，它是盘中条件、收盘条件还是公司事件条件。

数据不足以明确这些条件时，把该方案写成"需要重新分析的情形"，不包装成可以照做的买入信号。

特别禁止：当天收盘后才确认信号却假设能按当天上午最低价买入；只有一个盘中快照却声称"站稳半小时"；用部分成交额证明全天放量；收盘判断失效却默认能在收盘前按失效价卖出。

执行规则采用研究时点有效规则。普通 A 股当日新买入股份当日不能卖出，必须考虑；失效价不代表保证成交价。**V1 的默认执行假设：收盘确认后次一交易日正常竞价时段参与。**这是本功能的保守简化，不是对交易所规则的描述（2026 年沪市规则含盘后固定价格交易，V1 不接）。盘中已有充分证据的方案可讨论当日剩余正常时段，但须满足报价与可交易条件。

观察期从**假定的实际买入交易日**算起，买入日计为第一天；不知道买入日时只给条件化说明。第十天默认是重新判断的时间参照，不是强制卖出日期。

## 6. 买后怎样处理利润与失效

分开写四种情况：正常发展、发展不及预期、判断失效、上涨后回吐。用户想获利，不等于必须在第一个正收益时卖出，也不等于必须等一个大目标。

可以提出第一处观察区域、继续持有的证据、需要退出或重新评估的条件；用已有 ATR（20 会话真实波幅简单平均，写明口径）检查失效距离是否落在普通波动内。ATR 不是方向、概率或保证亏损上限；不设"所有股票 1.5 倍 ATR 止损"之类的通用规则。"N 天不走强就重评"只能是本次有理由的管理安排，不能成为通用强制规则。

## 7. 证据组织与缺口

- 本地事实起步：`context.json` 已含身份、日线、中性观察、公告元数据、财务摘要、原推荐背景与输入清单。不要把旧复盘的整套入口与目标字段搬进新研究。
- 按需外部补证：只对会改变买入结论的具体缺口读交易所、巨潮、公司公告等可靠原文。每条真正使用的材料保存：标题、发布方、链接、公开时间及精度、读取时间、支持的具体事实、页码/章节定位；只存用到的短摘录。`fetched_at` 不冒充 `available_at`；历史回看时版本无法确认就标"历史版本不明"。搜索摘要和新闻标题只能定位线索，不能代替重要金额、条款、利润归属的原文。
- 缺口只限制它实际影响的结论：关键交易价格/复权口径不可靠 → 不能给已满足的立即买入结论；关键催化条款未知 → 不能断言其利润作用，但可以继续说明可验证的价格事实；普通辅助指标缺失 → 可以不用，不机械否决整份研究。
- 盘中报价是独立快照：至少有代码、价格、报价时间、获取时间、来源。证明不了报价时间就不能支持"立即按现价参与"。

## 8. 边界

不修改五个选股 Skill 的输入输出合同；不加买入打分、权重、固定盈亏比门槛或新 Gate；不进入正式复盘、Forward CSV 或既有报告模型；不建持仓、账户、收益记账、自动跟踪；不接券商、不下单、不算仓位；不新增定时任务、实时推送、数据库或服务端；不承诺收益。报告结论允许是：参与、等待具体条件、暂不考虑、关键证据不足。
