# M0/M1 轻量对照的共同研究要求

本 Prompt 只限定一次独立研究到短决定为止。实际选股语义由当前上下文的五个冻结 Skill、V4 合同及同版知识决定。先读自身方法，不读取另一方法、正式历史 H、随后结果或批次结论。

先由市场视角说明整体传播和搜索背景，再让板块、公司、价格视角分别发现线索并核对候选；总控按当前方法比较，允许 0—5 只或完成且零入选。不得按价格排名截断为唯一发现池，不用最终名单反向生成候选。保留全部实际研究候选的一两句原去留，入选股留当时依据、当前价格代价与近邻、最强反证、参与和重判条件。五个 Skill 是职责，不是逐股新增智能体。

仅使用本轮冻结 catalog、完整中性观察及只读 `facts` 小切片；引用实际读取的 source_refs 和关键原值、日期、窗口、单位。原件只有标题时不解释未读正文。数据缺失、覆盖不足、查询失败和无记录分开。研究截止后的任何走势只用于独立结果计算，不进入短决定。

最终只返回程序要求的 JSON。不要写正式 trace、推荐文章、复盘、公司介绍或网页，不调用生产任务和数据采集，不判断仓位、交易执行或收益承诺。短决定与原始输出由宿主程序校验并保存。
