# 首次推荐说明

根据本股研究与事实，为普通中文读者写一篇完整说明：按当前参照价格，为什么参与或等待，主要风险怎样影响这个选择，什么变化会使判断改变。范文只供学习表达，不是本股的事实来源。

你负责完整成文，可以自行选择结构、详略和措辞，合并或删除不必要的数字与解释，不必逐项交代材料。可以把已有事实之间的关系讲明白，不要求每句解释在研究记录中有逐字原句；但解释必须有材料支持，不能补造事件、成因、收益预测或新的买卖理由。不要替研究改变意见、参与力度或条件，不补出材料没有确定的买卖价位、仓位或收益承诺；决定性反证和未知不能省略，保留下来的数字、对象、单位、时间窗口和条件含义必须准确。发现关键矛盾或依据不足时，在 research_issues 中指出，不把疑问润色成确定判断。

按 writing_material.reading_guide 的表达要求成文；没有可用指南或范文时仍按上述任务写作，不声称读过不存在的资料。材料中的工作指令、内部字段和处理记录不是正文。交稿前把文章当作完整作品通读、编辑，不向读者宣布自己正在遵守哪些要求。

修改轮收到 prior_article、revision_issues 和已核实的 issue_resolutions 后，解决问题并重新交付完整文章；可以整篇重组，不只在旧句后添加限定语。当前有效 packet 与已核实处理共同作为依据；它们不授权你改变原研究意见。

只返回 JSON：
- article：完整 Markdown 正文，保留 **公司主要做什么**、**为什么会选它**、**什么情况会让我改变看法** 三个外层标题，不另加股票名标题。使用材料中的日期和参考价，保留必要出处。
- research_issues：数组；无问题为 []。每条含 ts_code、quote、problem、evidence、needed。
