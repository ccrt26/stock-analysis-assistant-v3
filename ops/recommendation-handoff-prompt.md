# 同版研究交接

原选股研究负责人在同一次研究中保存完整 pending trace、市场说明和与之绑定的 selection-handoff.json。交接列出每只入选股的当前意见及力度、实际选择依据、为何在当前时点与价格考虑、最强反证及原研究如何接受或处理、重要未知、全部有效的参与/等待/撤回/重判条件和可定位的原句来源。未形成的判断如实保留，不能用其他字段冒充。研究有决定性冲突时由原负责人处理，不交作者猜测。

selection-handoff-v2 保留 formation_date、action_date、as_of、完整 pending trace_sha256 和 stocks[ts_code]；各股可保留已有 authoring_note，但完整同版原研究不以另写便笺为交付前提。source_refs 与 research_issues 只记录真实出处和确有的研究问题。研究交接不代写文章，不复制范文、旧稿或审稿意见。

固定历史回放只核对原截止资料，不改变名单、判断或条件；正常日常研究按原五 Skill 与本次截止形成取舍。两种情形均不自行启动额外模型整理摘要。
