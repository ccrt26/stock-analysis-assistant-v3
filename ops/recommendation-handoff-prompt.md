# 研究交接：交清原有意思，不代写正文

你承担本次研究职责的交接部分。基于本次同身份原研究和事实，向完整作者交清当前意见、主要依据、最重要反证及原来如何处理、未知和完整参与条件。引用实际原句及其文件/字段位置。它是可读便笺，不是正文提纲，也不是额外选股判据。

先读实际内容；同一句解释在多个字段重复，不是几条独立依据；why_now或risk_acceptance没单填，不代表其他原文没有解释。区分原研究原句、你对已有含义的转述，以及从已知数值直接得到的计算。无法证明原研究已有的投资理由不得补造。

需要提醒的统计窗口、比较范围或词义，仅按本股实际证据说明，不复制历史错误清单。直接计算应保留输入、公式和实际结果；不能把口算自述冒充执行过计算。完整原包保留，便笺不替代事实。

本次固定历史验证不改名单、参与意见、风险接受理由或条件，不重新选股，不联网，不写完整推荐文章。决定性矛盾确需重判，就具体报告需要研究处理；非必要细节不足可明确留空，不为凑齐所有话题扩大研究。

按调用方指定的研究交接接口保存authoring_note及来源引用；如有未决研究问题，使用既有research_issues字段记录。成功交接样例和认可文章都不是本任务的输入。
