# 价格主要场景 V2 预注册验证设计

## 1. 要回答的问题

本轮不再问“某个指标单独能不能预测上涨”，而是问：当原始价格、相对强弱、收盘路径、量能和必要技术状态共同形成一种可识别场景时，这种解释在之后 20 个交易日的路径上是否得到历史支持。

场景在本文件冻结后才读取时间后移期结果。结果只有 `supported`、`refuted`、`insufficient` 三种；失败的组合不换参数重试。场景可以重叠，不是评分、投票、Gate 或互斥状态机。

## 2. 数据与时点

- 复用冻结样本 `local_archive/price_indicator_validation/2026-08-19-price-indicator-validation-v1/frozen-sample.parquet` 的股票范围、形成日、行动日和 D1—D20 标签；从本地 `equity_daily + adj_factor` 按同一形成日重算 `price-indicator-conditional-states-v2`，只读取 `trade_date <= formation_date` 的价量。
- 形成日：2022-07-26 至 2026-07-21，每第 5 个开市日一次。开发期截至 2024-12-31；时间后移验证期为 2025-01-02 至 2026-07-21。
- 入口是行动日复权开盘价。`hit_20pct_d20` 使用 D1—D20 最高价是否达到入口价 +20%；`mfe_20d` 用期间最高价，`mae_20d` 用期间最低价，`return_close_d20` 用 D20 收盘价，均相对入口计算。
- 冻结样本已经排除行动日无有效价量、未来 20 日不完整及能通过 5% 涨跌幅带识别的特殊处理股票；历史 ST 名称、封板能否成交和完整行业相对收益不能无歧义回放，分别标为覆盖不足，不补猜。
- 样本曾被过去研究接触，本轮只能称为时间后移探索验证，不是独立盲测或因果证明。

## 3. 开发期分组

连续变量的 `Q20/Q40/Q60/Q80` 只用开发期非缺失值确定，再原样用于验证期。绝对值条件使用开发期相应绝对值分位数。零点、布尔交叉和是否突破使用公式本身，不搜索参数。

所有场景共同遵守：所需字段缺失即不进入该场景或对照，不以 0 补值；技术指标单独出现不能进入正面场景；对照组保留该场景的核心前置价格状态，只改变路径质量/确认条件。研究分位数不会写成每日生产硬阈值。

## 4. 冻结场景

下表中的“高/低/很高”分别指开发期 `Q60/Q40/Q80`，必要处直接写 `Q20`。`量价效率`指 5 日 `volume_price_efficiency_5d`，`长期量价`指 20 日 `signed_amount_balance_20d` 与 `price_amount_efficiency_20d`。

| 初步激活 | 20 日收益位于 Q40—Q60，5 日收益和相对市场高，成交额比高；MACD 近 5 日上穿且柱体增强、DMI 向上；收盘位置和量价效率高；涨停贡献非很高 | 同样的短期相对启动和放量，但 MACD/DMI、收盘或量价不确认 | 可参加发现；反证是单次交叉与短期脉冲 | 正向触达 |

## 5. 评价与判定

每个场景只在验证期评价，并按形成日等权比较场景组与对照组。报告两组样本数、形成日数、股票数、日期范围、20% 触达率，以及 MFE、MAE、D20 收益的个股中位数；比较值使用同一形成日内两组均值之差再对形成日等权平均。

按连续 4 个形成日组成日期块做 1,000 次确定性 bootstrap，报告主判据差异的 95% 区间。对 11 个预注册场景的预期方向做日期块符号翻转检验，并用 Holm 方法校正多重比较。

证据充足的最低覆盖为：场景组和对照组各至少 500 条、100 只股票、40 个共同形成日；2025 和 2026 各至少 100 条且 20 个共同形成日。低于任一要求直接为 `insufficient`。

- **正向触达场景**：触达率差至少 +3 个百分点、95% 区间下界大于 0、Holm 后预期方向 `p < 0.05`、2025/2026 均为正且 MFE 差为正，判为 `supported`。若触达率差至少 -3 个百分点、区间上界小于 0、反方向 Holm `p < 0.05` 且两年均为负，判为 `refuted`；其余不足。
- **负向触达场景**：方向相反，场景组触达率至少低 3 个百分点并满足同样的不确定性、校正和跨年条件，判为 `supported`；显著高 3 个百分点则 `refuted`；其余不足。
- **负向 D20 风险场景**：D20 形成日等权收益差至少 -2 个百分点、95% 区间上界小于 0、Holm 后预期方向 `p < 0.05`、2025/2026 均为负，且 MAE 更差或触达率更低，判为 `supported`；显著高 2 个百分点则 `refuted`；其余不足。

即使场景得到支持，也必须同时报告其绝对触达、MAE 和 D20 收益；“更容易中途触达”不能改写成“更适合买入或持有”。

## 6. 行动日事实覆盖层

行动日停牌、无报价、无成交、一字涨停/跌停或价格明显脱离原命题，覆盖在全部场景之上。它们不参与场景预测、不被技术状态抵消。现有冻结样本不能完整还原封单可成交性与所有历史特殊处理名称，因此本轮只验证已记录的有效价量和 5% 限制排除；其余保持未知。

## 7. 产物与禁止事项

- 冻结 `v2` 场景特征、开发期阈值、逐场景统计、结果 JSON 和输入说明到 Git 忽略的 `local_archive/price_indicator_validation/` 新目录，不覆盖 V1。
- 只有 `supported` 的组合可作为正面或风险解释写入价格 Skill；`refuted` 必须写入禁止解释；`insufficient` 只能作为待核问题，不能由 AI 自行补故事。
- 不修改其他 Skill、正式选股逻辑、数据库 schema 或 `opportunity_type`；不重新选股；不建立总分、权重、Gate、参数搜索、状态机或通用匹配系统。

## 8. V2 实现错误与冻结更正

首次执行目录 `2026-08-19-price-scenario-validation-v2` 在打开结果后被判定为无效运行，结果不得用于 Skill。原因有且只有两项：

1. 开发期 `limit_up_return_contribution_5d` 的 Q20/Q40/Q60/Q80 全部为 0；“非很高”被实现成 `< Q80`，使既有趋势、初步激活、有效突破和反转尝试的场景组必然为空，“很高”又会错误包含所有 0 值。更正为：原字段仍完整报告；凡需区分“很高/非很高”，只在开发期正值子样本内计算 Q20/Q40/Q60/Q80，场景条件与对照条件仍保持原来的 Q80/Q40 位置，不读取验证期结果。
2. 无样本场景产生的 `NaN p` 污染 Holm 递推，导致有效场景的校正值被错误推到 1。更正为：预注册但无法计算的假设按 `p=1` 保留在 11 项家族中，既不提供显著性，也不污染其他有限 p 值。

除上述确定性错误外，场景条件、主判据、效应门槛、覆盖门槛、样本期和多重检验方法均不改变。V2 特征本身未受影响，可以按哈希和身份集合复用；修正后的完整场景评价使用新运行目录，不覆盖 V2。
