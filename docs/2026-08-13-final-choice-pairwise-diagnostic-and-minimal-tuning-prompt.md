# A股五 Skill 最终取舍成对诊断与最小调优 Prompt

## 唯一目标

在不扩大候选池、不改变股票范围和“未来约20个交易日形成可操作显著上涨路径、重点观察约20%涨幅”目标的前提下，查清总控为什么会在同一形成日选择相对较弱的股票，却淘汰形成日证据更强、后来命中20日主目标的候选。

本轮只调优**候选已经进入共同验证之后的最终取舍**。未来结果只用于定位需要复查的选择和评价已经冻结的选择，不得反过来制造形成日理由。

在留出样本未受污染的前提下，允许的最终结论只有三种：

1. `保留修改`：发现跨日期重复的具体取舍偏差，完成一次最小修改，并通过新留出日期验证；
2. `回退修改`：开发样本允许尝试修改，但修改未改变留出选择或未通过预定保留条件，已恢复原 Skill；
3. `证据不足，不修改`：没有发现达到门槛的重复取舍偏差。

不得为了得到“保留修改”而降低证据门槛。

如果在形成日答卷全部冻结前已经读取任何新留出日期行动日及之后的行情、评价或带有未来结论的文件，预冻结前提即不成立。此时不得更换日期、不得继续调优或输出上述三种研究结论，应停止并向用户报告真实阻碍。

## 固定目标与评价口径

- 形成日研究只使用 `available_at <= as_of` 的事实；`as_of` 为形成日 `23:59:59+08:00`。
- 后来发布的复盘、修订数据、当前身份或未来公告不能倒填为形成日证据；无法证明当时已可得的信息记为未知。
- 行动日为形成日之后第一个真实交易日。
- 入口沿用现有口径：行动日可正常参与时以开盘价评价，统一使用同一复权序列。
- 主标签是行动日起20个交易日内，任一收盘相对入口达到项目现有“约20%”阈值。若现有 Skill 没有唯一数值定义，必须在读取任何候选未来结果前统一固定为 `>=20.00%`，所有开发和留出日期不得改变。
- 行动日计为第1个交易日；前10个交易日达标与第11—20个交易日才达标只记录启动速度，不替代20日主目标。
- 20日终点为第20个交易日收盘相对入口的收益。
- 平均最大收盘涨幅使用20日内最高收盘相对入口的收益。
- 最大不利变化使用入口至首次达标日、未达标时至第20日之间的最低复权价相对入口的收益；数值越高、即越不负，表示越好。
- 相对市场终点为个股20日终点减去同一行动日开盘至第20日收盘的市场基准收益。优先沿用项目已有唯一基准；若项目未定义，在读取任何未来结果前固定使用中证全指并记录实际数据代码，之后不得更换。
- 最终仍允许0—5只，不因样本、名额或评价方便而降低绝对入选标准。
- 所有汇总平均值以可执行入选股票为等权单位，同时列出逐日结果；命中率分母为可执行入选数。若当前版或修改版在全部留出日期没有任何可执行入选，命中率不可比，修改不得保留。

## 使用的五个 Skill

- `orchestrating-stock-research`
- `interpreting-market-macro`
- `researching-sectors-industries`
- `researching-company-events`
- `analyzing-price-trading`

四个专业视角提供形成日事实和反证，总控承担最终选择责任。四个视角不是投票，不按来源数量、证据条数或文本完整度排序。

## 留出日期形成日基线

此步骤必须在开发样本成对诊断之前完成，且不得读取新留出日期行动日及之后的任何行情、评价或未来叙述。

使用当前未修改的五个 Skill，为三个新留出日期分别保存：

- 统一时间边界、历史时点股票范围和可执行性规则；
- 四个专业 Skill 实际提交的全部线索及其 `available_at`；
- 去重候选池及每只候选的四视角支持、反证、未知；
- 每只候选唯一去向和主要原因；
- 当前版最终0—5只、行动日条件和放弃条件；
- 对每只入选股，明确同日最接近的淘汰替代股票，以及为什么选择前者；
- 候选守恒表：四个专业 Skill 提交线索去重后的股票代码集合，必须与 `selected + rejected + unresolved` 的互斥并集完全一致。

三个日期的候选池、证据账和当前版答案保存后不得根据开发偏差或未来结果改写。后续修改版只允许在这份已经冻结的证据账和候选池上重新执行总控最终取舍，不得重跑四个专业 Skill、补搜来源或加入新事实。

## 开发样本的成对诊断

### 1. 恢复真实候选账

逐日读取既有 `candidate_chain` 和20日评价，核对：

- 每只股票的形成日去向是 `selected`、`rejected` 或 `unresolved`，且三者互斥；
- 去重候选集合等于三种去向的并集；
- 未来评价与股票代码、形成日、行动日一一对应；
- 只比较行动日可执行且未来20日数据完整的候选；
- 数据缺失、不可执行、发现遗漏和形成日后才出现的催化单独处理，不混入取舍错误。

### 2. 建立“选A弃B”对照

未来结果只负责定位需要复查的主目标倒置：

- A为同日实际入选、行动日可执行但未来20日未命中主目标的股票；
- B为同日已经进入候选、行动日可执行却被淘汰，并在未来20日命中主目标的股票；
- B与优先共享同一上涨原因、同一板块或同一机会类型的A配对；没有同因果链对象时，才与同日最接近的替代机会配对；
- 每只B只与最相关的一只A比较，不为凑数量重复配对；
- 若B和A的20日主标签相同，只能作为次要表现差异记录，不得计入 `decision_miss` 或修改门槛。

每一对只使用形成日证据，在同一张表中对称比较：

1. 形成日前出现的真实新变化；
2. 对收入、利润、现金流或预期的传导及材料性；
3. 催化是否可能在未来20日继续兑现；
4. 市场和板块是在提供支持，还是只解释共同上涨；
5. 价格识别程度、透支反证和仍可参与的剩余路径；
6. 最强反证、关键未知及数据质量；
7. 当时保留A、淘汰B所实际依赖的一条首要决定性差异；若无法识别，明确记为无法归因，不得补造理由。

不得打总分、设固定权重或把七项变成七道 Gate。

### 3. 严格定义真正的取舍错误

未来主标签倒置只决定是否进入复查，不决定错误成因。B只有同时满足以下条件，才记为 `decision_miss`：

- 已经进入当时候选池，不是 `discovery_miss`；
- 与A均行动日可执行且20日数据完整；
- B命中20日主目标而A未命中；
- 按当前总控 Skill 在形成日可得证据下，B本身达到现有绝对入选标准；报告必须引用该标准的具体原文或明确对应规则；
- 能指出当时用于保留A、淘汰B的同一决策标准被不一致地应用，或决定性差异不受形成日证据支持；
- B应被保留的理由完全来自形成日事实，不来自其事后涨幅、未来公告或结果倒推；
- A和B的数据能力差异没有被误写成公司、催化或价格优劣。

以下情况不是 `decision_miss`：

- B的决定性催化在形成日之后才出现；
- B只有板块或价格异动，无法确认公司传导；
- B虽一度冲高，但未命中20日收盘主目标；
- B依赖缺失正文、后来修订数据、当前身份倒填或其他当时不可得信息；
- A与B主标签相同，只是速度、峰值或终点不同；
- 只是因为当日未满5只，就认为B应被补入；
- 原取舍存在形成日证据支持的一致标准，即使结果后来不利。

### 4. 归纳偏差而不是解释个例

只检查以下类型是否由证据自然重复出现，不预设一定存在：

- 过度惩罚此前已经上涨，忽略仍在强化的直接公司变化；
- 过度偏爱低位或较少上涨，把“没涨”误写成剩余空间；
- 低估直接业绩、订单、并购进展或经营拐点，过度看重板块和量价共振；
- 把多来源支持当成票数，压过单一但更强的公司因果链；
- 对A和B的相同风险、未知或透支使用不同标准；
- 只分别分析候选，没有真正回答为什么A优于最接近的B；
- 没有区分催化已经发生与未来20日仍可能继续兑现。

某种偏差只有满足以下全部条件，才允许修改：

- 至少在两个不同开发日期各出现一个 `decision_miss`；
- 两个实例属于独立形成日决策；同一A/B组合和同一未变化催化的机械延续只算一个实例；
- 能指出相同的形成日判断偏差，而不是只有相同的未来涨幅；
- 当前总控 Skill 对该比较缺失或表述含糊；
- 在不改变证据账和候选池的反事实重判中，修正该偏差会改变至少两个开发日期的实际最终取舍，而不只是增加报告字段。

若门槛不满足，立即确定为 `证据不足，不修改`：不改 Skill，不读取新留出未来，完成报告并明确留出形成日答卷仍保持未开封状态。

## 唯一允许的最小修改

如果开发样本达到修改门槛，只允许对 `orchestrating-stock-research/SKILL.md` 的最终取舍纪律做一次最小文字修改：

- 只修正已经重复证明的一个偏差；
- 只作用于已经冻结候选池内部的比较；
- 不修改另外四个专业 Skill；
- 不增加候选、数据源、评分、阈值、权重、配额、Gate或第二轮全市场扫描；
- 不改变20日目标、股票范围、可执行性和数据质量规则；
- 不把事后结果、具体日期或具体历史股票写成未来规则；
- 保存修改前后原文和最小 diff。

修改后，在仍未读取留出未来的情况下，只使用已经冻结的留出证据账和候选池重新作最终取舍。基线版与修改版每个日期的候选股票代码集合必须完全相同，只允许最终去向和选择理由因新纪律发生变化。

“A/B取舍发生变化”包括以同一绝对标准发生的替换、增选或剔除，但不得因5只名额本身增选，也不得降低绝对标准。

如果修改没有改变至少两个开发日期的目标A/B取舍，立即恢复原 Skill，结论为 `回退修改`。如果修改改变了开发取舍，但三个留出日期的最终选择均未改变，也应在不打开留出未来的情况下恢复原 Skill，结论为 `回退修改`。

## 新留出日期只打开一次

只有以下内容全部完成并冻结后，才可以一次性读取三个新留出日期行动日起的20个交易日行情：

- 当前版三份完整形成日答卷；
- 开发样本全部A/B对照、`decision_miss` 判定和唯一偏差定义；
- 唯一修改文本；
- 修改版三份形成日答卷；
- 当前版与修改版之间至少一个留出日期的最终取舍变化。

打开未来后不得再次修改 Skill、偏差定义、日期、证据账、候选池或选择理由。

分别汇总当前版和修改版：

- 入选股票数、可执行数；
- 20日收盘目标命中数和命中率；
- 前10日与第11—20日命中数；
- 平均最大收盘涨幅；
- 平均20日终点及平均相对市场终点；
- 平均最大不利变化；
- 逐日当前版与修改版的选择变化及对应结果。

修改只有同时满足以下条件才保留：

1. 每个留出日期的候选股票代码集合完全不变；
2. 修改版至少改变一个留出日期的最终取舍；
3. 当前版和修改版均至少有一个可执行入选；
4. 修改版20日目标命中数和命中率都严格高于当前版；
5. 修改版平均相对市场终点不低于当前版；
6. 修改版平均最大不利变化不差于当前版，即数值不低于当前版；
7. 没有新增不可执行股票；
8. 改善可由预先定义的同一种取舍偏差及冻结前已写明的选择变化解释，而不是新的事后解释。

任一条件不满足，恢复原总控 Skill，最终结论为 `回退修改`。三个留出日期样本仍然较少，即使通过也只说明这次最小修改值得暂时保留，不宣称已经证明长期收益。

## 执行顺序

1. 记录当前工作区状态，保护用户无关改动；确认本轮尚未读取留出未来。
2. 在不读取价格的前提下核对开发和留出日期、行动日及20日窗口，只使用交易日历；冻结“约20%”数值阈值、市场基准和计算公式。
3. 为三个新留出日期生成当前版完整形成日答卷并冻结候选池、证据账和选择，不读取未来。
4. 对三个开发日期恢复候选守恒账，建立主目标倒置的A/B对照并逐对判定 `decision_miss`。
5. 汇总跨日期独立重复偏差，按门槛决定是否允许修改。
6. 未达到门槛：不改 Skill，不打开留出未来，写报告并结束为 `证据不足，不修改`。
7. 达到门槛：只修改总控一次，先用冻结的开发证据确认至少两个开发日期取舍改变，再用冻结的留出证据重做最终取舍。
8. 修改未改变开发或留出取舍：恢复原 Skill，不打开留出未来，结束为 `回退修改`。
9. 两版留出形成日答卷均已冻结且存在选择变化时，一次性读取新留出未来结果。
10. 按预定保留条件决定保留或回退，不进行第二轮修改。
11. 运行五个 Skill 格式校验、相关项目测试和 `git diff --check`。
12. 写入完整报告，检查需要同步的成果；只在上位请求已经明确授权提交和推送时，提交本轮 Prompt、报告和最终保留的 Skill 修改，不纳入无关文件。

## 执行纪律

- 未来结果只能定位开发样本中的主目标倒置，并评价已经冻结的留出选择，不能改写形成日事实。
- `decision_miss` 必须与实际入选A作形成日证据对照，不能把所有后来上涨的淘汰股都算作错选。
- 不扩大候选池，本轮不处理 `discovery_miss`。
- 不把公司、板块、价格、市场四视角当投票。
- 不用低位、前期下跌或较少上涨单独证明剩余空间。
- 不用此前上涨或高位单独证明已经透支。
- 不因信息更完整就自动优先，也不因数据缺失就补猜。
- 不搭建新回测系统、数据库、扫描平台、评分器或报告框架。
- 不做红绿流程、哈希封存、模型反复采样或多轮子智能体评审。
- 除本 Prompt 的一次独立审查外，后续由主智能体完成；只有出现主智能体确实无法完成的能力要求时才允许额外子智能体。
- 不覆盖、清理或提交 `AGENTS.md`、`bingo/`、`who-is-it/` 及其他无关用户文件。

1. 本 Prompt；
2. 一份完整报告，至少包含：
   - 固定日期、时间边界、主目标阈值、市场基准、计算公式和数据限制；

   - 开发日期全部主目标倒置A/B对照；

   - 修改前后开发取舍变化；
   - 新留出日期当前版与修改版结果；若未打开未来，明确说明原因和未开封状态；
   - 保留、回退或证据不足的唯一结论；

4. 若发生同步，列出分支、提交号和实际同步内容。
