# 价格 Skill 后续验证执行 Prompt

## 目标

完善价格 Skill 对价量、相对强弱和技术指标组合的实际用法；同时写清 D20 后如何验证，并规定每天只保留足够复核当时判断的最少证据。

## 验收

1. 六类价格信息共同参与判断，11 个场景作为研究假设使用，不做指标投票、评分、Gate 或自动结论。
2. 已有历史结果按效果、区间、稳定性、样本和风险分别解释，不再以任意 `3%` 单门槛决定场景去留。
3. 形成日只为实际入选股和最近未入选股保留：时间边界、必要原始价量、相关指标、使用的 1—2 个场景或原始价格判断、它如何改变取舍、最强反证与未知。
4. D20 后能用冻结记录复核场景解释和 AI 当时的用法；缺失记录不得事后补猜。

## 范围与不做事项

只修改价格 Skill，并留下一份简明的形成日留证与 D20 评测方法。复用已有本地行情、指标公式、历史研究结果和 Forward 记录；不新增生产模块、派生分区、数据库、schema、CLI、自动状态机、评分或测试框架，不重做选股，不读取未来行情，不修改既有 Forward 日志，不提交或 push。
