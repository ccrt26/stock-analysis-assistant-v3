# 价格归因调优 Prompt

## 任务性质

这是一次单点、可回滚的 Skill 调优。Prompt 审查通过后自动连续执行到验证和汇报；只有必须由用户授权的外部动作，或者证据迫使任务目标或修改范围发生改变时，才停下请求介入。

## 唯一调优目标

修正 A 股价格研究中对“启动”和“剩余空间”的误判：

- 先区分个股上涨主要是大盘普遍修复、板块共同上涨，还是个股自身出现增量强势，再描述“重新活跃”、“初步确认”或“有效识别”。
- 当短窗口上涨大部分可由市场或板块共同变化解释时，只能写成市场带动或板块带动的修复，不写成个股独立启动。
- 过去 20 日跌得多、历史位置低，只说明前期回撤和当前位置，不能单独推出“还没涨”、“有补涨空间”或“已经启动”。
- 对无法可靠取得市场、板块或近似同类基准的情况，保留“来源无法判断”，不用绝对涨幅强行补判，也不因为证据不完美就自动否定候选。

这次不以“永鼎股份必须入选”为目标。`2026-08-11` 永鼎股份只是已暴露的开发案例，用来检查是否把“板块带动的短期修复”误写成“个股启动”；不读取、不使用 `2026-08-12` 及之后的价格反推形成日结论。

## 冻结范围

原则上只允许修改：

`.agents/skills/analyzing-price-trading/SKILL.md`

允许的实质性编辑最多两处，并且必须都直接服务于上述唯一目标。不改 Skill 的名称、触发描述或总体职责，不重写整个 Skill。

如果证据表明必须修改总控、市场、板块、公司、数据层或代码才能完成该目标，停止实施并汇报证据，不自行扩大范围。

## 已冻结的设计

采用“在现有判断流程中补齐归因语义”的最小方案：

1. 在“拆分价格来源”中补足判断顺序：大盘→板块/近似同类→个股增量；短期绝对上涨不能跳过这一归因。
2. 在“判断剩余路径”中补足语义边界：20 日负收益或低位不等于剩余空间；启动和确认用语必须与前述归因一致。

不在输出合同中新增字段。现有 `comparative_reason`、`remaining_path_reasoning`、`strongest_counter_evidence` 已能承载该结论。

不采用以下方案：

- 不新建“重新活跃—初步确认—有效启动”的固定状态机；
- 不新建技术指标总分、阈值、权重、排名或 Gate；
- 不增加新数据源、新表、新脚本或回测系统。

## 编辑前基线（RED）

价格 Skill 的精确编辑前 SHA-256 为：

`992cb05694f7af9880bf706359aa875cf2bf519b3fa604599853bdabe767f1d6`

已暴露的失败不是“Skill 完全没有相对强弱”，而是现有文本只要求列出绝对、市场、板块和自身历史四类比较，没有要求在使用“启动”前先说清主导来源。因此，在大盘和板块普遍修复时，分析可能同时列出“5 日转强”和“20 日仍下跌”，却把两者组合成“重新启动且还有空间”。用户对 `2026-08-11` 分析的质疑已构成编辑前真实失败样例；不用修改后自造的重放冒充历史原始产物。

在修改 Skill 前，必须先用下列冻结案例对编辑前文本做一次是/否基线检查，记录它是否明确约束了目标行为。预期 RED 结果是：它虽提到相对比较，但未明确约束下列用语，因而至少一项失败。如果编辑前文本已全部明确满足，不修改 Skill，直接汇报基线与用户观察不一致。

## 冻结案例和验收结论

所有案例只使用 `2026-08-11 23:59:59 Asia/Shanghai` 之前可得的形成日事实。下列数值是形成日截面的冻结输入；执行时只核对来源和语义，不看未来收益。

### 案例 A：永鼎股份 `600105.SH`

- 5 日收益 `+9.24%`，已派生的相对市场收益约 `+7.88` 个百分点。
- 最接近的“通信线缆及配套”组 5 日收益约 `+8.52%`，个股仅比组内共同变化高约 `0.72` 个百分点。
- 20 日收益约 `-22.92%`，组 20 日收益约 `-12.67%`；个股长窗口仍落后组内共同路径。
- 成交额相对参考窗口约 `0.68` 倍，没有成交放大支持个股独立识别。

验收结论：可写成“板块带动的短期修复/重新活跃，个股独立确认不足”；不得写成“个股已经有效启动”，不得用 20 日跌幅论证剩余上涨空间。

### 案例 B：江波龙 `301308.SZ`

- 5 日收益约 `+24.24%`，已派生的相对市场收益约 `+22.87` 个百分点。
- 最接近的“数字芯片设计”组 5 日收益约 `+7.88%`，个股比组内共同变化高约 `16.36` 个百分点。
- 20 日收益约 `-22.47%`，组 20 日收益约 `-15.58%`；长窗口负收益仍是伤痕和反证，不是空间。
- 成交额相对参考窗口约 `1.46` 倍，并存在形成日前公司/业绩事实可供公司 Skill 独立验证。

验收结论：可写成“短窗口同时超过市场和板块，个股自身初步价格确认较强”；仍需提示长窗口伤痕、事件传导和追涨反证，不得把低位自动写成剩余空间，也不得把“初步确认”写成未来保证。

### 案例 C：药石科技 `300725.SZ`

- 5 日收益约 `+23.63%`，最接近的“医疗研发外包”组约 `+23.32%`。
- 20 日收益约 `+21.34%`，组约 `+20.29%`；个股在两个窗口都主要跟随组内共同变化。
- 60 日价格位置接近窗口高位，成交额相对参考窗口约 `2.0` 倍。

验收结论：绝对涨幅很大也不等于个股独立启动；应写成“高位的板块跟随，成交活跃但需检查透支和供给压力”，不得仅因放量上涨写成个股独立有效启动。

## 验收标准（GREEN）

修改后的 Skill 必须同时满足：

1. 在市场或板块普涨/修复时，价格结论先说明市场、板块和个股增量分别解释了什么。
2. 个股与最接近板块/同类表现接近时，只写市场或板块带动的修复/跟随，不写个股独立启动。
3. 个股相对市场和板块/同类都有清晰增量，且量价推进、事件时点与反证的组合没有否定时，允许按证据强度写个股自身初步确认；不把它写成固定 Gate 或未来保证。
4. 20 日负收益、前期跌幅或低历史位置不再单独支持“剩余上涨空间”、“补涨”或“启动”。
5. 弱市中的显著相对强势仍能被识别；这次不把“必须市场、板块都上涨”写成前置条件。
6. 基准、板块或近似同类不可靠时明确未知；不用绝对涨幅补判，也不把次要未知自动升级为否决。
7. 不破坏现有事件后价格确认、透支风险、成交背离、可参与性和时间切片约束。

这是语义验收，不建立数值总分、统计显著性、收益率胜负线或新回测框架。

不为此新建永久测试脚本、测试框架、评分表或报告系统。

## 停止与回滚条件

下列任一情况立即停止实施，不做第二轮补丁：

- 编辑前 Skill 已经明确约束了全部目标行为，真实失败不在该 Skill。
- 价格 Skill 的 SHA-256 与冻结值不同，且无法安全区分并行改动。
- 必须改动第二个 Skill、数据层或代码。
- 最小编辑无法同时通过三个案例和反向检查，或它把市场/板块相对比较变成固定 Gate。
- 已完成一轮最小修改和冻结验证。

如果验证不支持修改，只逆转本轮对价格 Skill 新增的补丁，不使用覆盖、`checkout`、`reset` 或其他可能抹掉用户原有改动的方式。保留本 Prompt 和验证记录。
