# A2 主用页面切换实施方案

## 目标与验收

用户批准 A2 作为日常主用 WEB；原 Prism 作为停更备用。保留两个现有地址：主用 `style-preview/prism-a2.html`，备用 `prism.html`。沿用当前研究、归档、服务和晚间任务；主用直接从正式归档及截止前本地事实构建，停止借用备用 HTML 作为数据中转。完成实现、相称的检查及真实本地切换，核对差异后提交并推送 GitHub。

验收：新版可独立连续更新，正式快照逐字段与共享组装结果一致；价量补充只用报告截止前可见事实；完整复盘与推荐时点公司资料可在新版阅读；主用与日期页正常生成且保留原子替换、旧日期不覆盖新首页、失败保留旧首页；旧版 HTML 在一次性停更标记之后不被常规生成或补跑改动；正式研究归档不改；桌面/手机、核心图表、筛选、收藏、详情交互正常；仓库不含本地事实、HTML 成品、凭据和本机路径。

## 范围与实施步骤

1. 保存并沿用工作区已有 A2 模板、样式、脚本、测试及其修改记录，不覆盖用户已验收的黑白布局。先做恰好一次独立上下文方案审查，通过后才实施，不再委派。
2. `tools/render_prism_web.py` 继续作为唯一正式同步入口。沿用现有正式归档严格校验、数据组装与指数附加；将最后的渲染替换成 A2，并在相同冻结截止内组装价量补充日线。固定输出改为 `style-preview/prism-a2.html`，新日期输出为 `prism-a2-report-<date>.html`。保留原有 `--date/--action-date/--as-of`、同步状态输出和锁/原子写入/发布前源文件变化检查/较新首页保护；常规生成不写备用或旧 `prism-report-*`，`--out` 也禁止绕过到这些路径。
3. A2 构建模块提供纯渲染及补充日线组装能力。停止默认从旧 HTML 提取快照并覆写主用页的旧用法；原 A2 命令改为转交唯一正式同步入口，避免日后误把冻结备用内容重新发布到主用页。模板使用一次替换，保证正文中与占位符同名的文字不受二次替换；无效数据或补充价格冲突失败，不偷偷替换研究数据。
4. `tools/stock_ai.py` 的现有同步调用及恢复流程不另起任务，页面就绪检查跟随新的日期页与固定路径，避免仅凭备用页存在就判断主用已就绪。现有公司介绍补齐后再次同步仍走同一命令。同步更新运行 Prompt、当前架构及 Prism 使用说明，只描述展示交接，不改研究判断/日期/正式存储合同。
5. 新版标题、页头、页脚和说明改成主用身份，备用链接明确标注停更。保留现有浏览器收藏键和交互。将星图的详情按钮、个股弹窗、观点阅读连接到同一条推荐记录的完整复盘阅读；在弹窗提供走势、完整复盘、公司资料，按推荐身份读取现成 `companyIntroduction`；查看历史复盘时按所选复盘日期展示相应正文与价格截止，公司资料始终为原推荐时点。正文完整保留、转义显示，缺项按实际说明，不编造或模型改写。外部来源链接仅允许安全 URL。补齐详情最小必要样式，不复制或恢复旧版整套界面。
6. 本地切换前在临时目录保存旧版及新版现有成品用于恢复。对备用 HTML 仅做一次静态“备用版，已停止更新”与最后数据日期标记，保持其嵌入快照和交互内容。此后不由定时同步重新写备用。使用最近完整正式归档及其原三个时间参数渲染新版；不运行 prepare/record、不重跑研究、不重建旧日期网页。
7. 检查并交付：更新既有渲染/自动任务测试，验证新入口、无备用依赖、旧页不写、空名单、源变化/补充冲突/生成失败保留首页、日期回退保护及正文转义；A2 测试改为临时目录和合成最小快照，真实事实仓核对单独按需执行，避免普通测试写主用页或依赖固定本地日期。运行涉及模块的 pytest、JS 语法检查、真实页面 Playwright 核对与截图（含完整复盘/公司资料/历史日期/手机/收藏/搜索），发现问题限定本范围修复。核对正式归档及备用内嵌快照未变，常规重跑不改备用，HTTP 两个原地址仍可访问。
8. 审查最终差异和提交清单，已有 A2 未提交改动作为用户批准的页面基础一并纳入。只提交本次源码、文档及测试；检查远端状态，常规提交并推送，不强推、不覆盖他人改动。汇报两个入口、关键改动、实际检查结果、GitHub 提交和剩余限制。

## 约束

不引入新服务、任务、云端架构或依赖；不改五个选股 Skill、选股/复盘结论、Forward CSV、正式归档、D20 冻结、事实仓和实时行情策略。新日期页面仅展示既有冻结结果。需要修改方案外高风险内容时先停止该部分并说明。若实际外部权限或工具能力阻塞推送/检查，报告真实结果，不宣称完成。

## 审查与执行记录

独立上下文审查结论：通过。审查确认无需修订；实施覆盖个股及指数补充冲突，历史阅读只按已有数据的所选日期截断，不声称重新取得原时点快照。

## 实施与验收结果

- 已完成主用独立取数、正式同步输出及自动任务就绪路径切换；A2 原地址继续使用，新日期页正常生成。
- 已补齐个股完整复盘、原推荐、当前参与意见、D20 固定结案及推荐时点公司资料入口；历史日期按已有冻结数据截断。收藏沿用原存储键，排序与取消收藏保持当前页面。
- 旧版只加一次停更标记及主用链接，内嵌快照未改。正式同步重跑确认主用、日期页、备用的内容及修改时间均保持不变；源码测试另验证输入变化、失败和补跑日期保护。
- 263 项相关 pytest 通过，四个 A2 JavaScript 文件语法检查通过；52 项真实浏览器检查通过，覆盖量价、完整原文、公司资料、历史日期、收藏/搜索/星图、320—1920 像素布局、手机资料阅读、减少动效和合法空名单。
- 桌面与手机截图已人工查看。两个原地址及新日期页 HTTP 200，响应与文件一致；停更备用链接可打开新版详情，无脚本异常。
- 新版快照与切换前发布快照逐字段一致；本次五份正式归档输入字节不变。页面中既有资料缺项继续按实际显示，不为切换补写研究。
- 提交清单只含源码、文档及测试；本地成品、恢复副本、截图和研究数据不进入 GitHub。
