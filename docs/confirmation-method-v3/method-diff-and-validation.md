# 方法差异与验证

## 旧文与替换

基线为 V2.1 已交付提交 `a1fcef2f1c6e3a99b47d4a5186fec91179f8e64c`；本分支的完整逐行替换以 `git diff a1fcef2 -- .agents/skills docs/architecture/a-share-short-horizon-engine-contract-v4.md ops/forward-selection-prompt.md` 复核。下列是决定性旧文和现行全文。

**价格 Skill 3A，旧文：**

> 当 `largest_positive_day_contribution_5d >= 0.50`，或已有可靠事实显示 `limit_up_return_contribution_5d >= 0.50` 时，进入单日主导判断。最大上涨日就是形成日且没有后续交易日、最大上涨日之后收益为负或相对市场转弱、去掉最大上涨日后其余四日不涨，都不能写成持续性已经确认。纯价格型只有其余交易日仍上涨且最大上涨日之后继续走强，才继续与其他候选比较；信息型按下一段的早确认合同比较，仍保留单日集中反证。没有可靠涨停证据时保持未知，不新增字段或数据源；这项判断不自动淘汰所有涨停股，也不改变 `fresh_event_pending`。

**价格 Skill 3A，替换全文：**

> 当 `largest_positive_day_contribution_5d >= 0.50`，或已有可靠事实显示 `limit_up_return_contribution_5d >= 0.50` 时，进入单日主导判断。纯价格型须先有多个普通交易日的独立正向推进，剔除最大上涨日后仍有实际正向进展；最大日之后略负或没有再创新高不能单独推翻此前已形成的支持。只有在最大日之后已完成正常交易，才能声称检验过保持；若最大日恰为形成日，则分开写明此前已获确认与其后尚未观察的表现，不能把当天上涨冒充后续保持。使用观察开始前已记录、或由此前日线重建的相关参照，注明日期、价格、来源及其距当前价的距离；不得用后见最低点或任意旧低点构造支撑。逐日核对收盘、相对市场和行业、成交及反证：孤立急涨加横盘、其余交易日无独立进展、持续丢失成果或相对优势、反复放量回吐，均不能借“保持”获得确认。信息型仍按下一段早确认合同判断，并保留单日集中反证。没有可靠涨停证据时保持未知，不新增字段或数据源；这项判断不自动淘汰所有涨停股，也不改变 `fresh_event_pending`。

顶部原则、3A 后续纯价格句、发现与验证、共享 review 中把多个更高收盘视为唯一证明的句子同步改为事实解释；review 不改变原推荐评价或当前机会合同。

**总控同行比较，旧文：**

> 同行比较依次看行业或公司变化是否仍在继续、去掉最大上涨日后是否仍强、最大上涨日之后是否继续强、成交增加是否形成多个较高收盘、最近 5 日和 20 日已经付出多少涨幅，以及同类中是否已有处在更早阶段但具备真实确认的股票。在其他条件接近时，优先确认已经出现但价格尚未主要靠一次大涨完成的候选，不偏向区间涨幅最大者。

**总控同行比较，替换全文：**

> 同行比较依次看行业或公司变化是否仍在继续、去掉最大上涨日后还有何实际正向进展、最大日后是否继续推进或有依据地保持、成交与相对表现有无失速、最近 5 日和 20 日已经付出多少涨幅，以及同类中是否已有更有余量且具备真实确认的股票。确认充分后比较新增观察解决了什么疑问、当前参考价距相关区域和障碍有多远；不按更多上涨天数累加确信，也不因较低涨幅自动优先。

总控另在最终取舍和再次推荐位置要求比较上次以来增强或减弱的事实、当前入口及原近邻；不禁推、不按重复次数升级。保持只是可用价格证据，不能自动入选。

## 接口与不变边界

`tools/stock_ai.py` 已使用仓库内 `ops/forward-selection-prompt.md`；该 Prompt 现明确在候选验证时读取价格参照、日线、相对与成交，并将当前入口和原前次记录分开。`recommendation_context.candidate_context` 已支持 `--root`、`--sector-date` 和 `--compare-code`，没有另造旁路选择器。现有 V4 价格校验只核原值与路径字段，不强制最大日后为正。没有发现程序端“末日必须收高”的候选前置过滤，因此未改候选生成或 V4 校验。直接阻断原事实交接的财报期间混合类型排序已局部修复。

普通板块 3/5 日资格、信息型 early 的新增信息和完整首个响应日、纯价格独立正向证据、正式支持原值、七种发动机、11 个场景、原20日目标和历史身份均保留。板块只补同口径跨日变化说明；公司和市场已有等价职责，未重复改。知识登记仅新增未验证的候选方法，文献是单日集中与成交解释的间接提醒，不能证明新方法盈利。本轮按用户要求未访问公网；V3提及而本地未登记的特定论文与网页未重新核验，不能当直接支持。

## 验证层次

- 程序：从本工作树导入的 14 个定向实例全部通过（六个 V4/early 原边界，三个只读事实/日期接口，三个 Skill/知识合同，两个运行 Prompt）。混合 `report_period` 先有复现失败例、修复后通过；没有运行整仓 pytest。命令及输出保存在私有执行记录。
- 行为：私有包保存 B1—B8 合成边界和十个真实形成日观察点的 M0/M1 同截止原始短判断；判断与后来收益分开冻结。
- 行为对照：十个真实点有三处取舍改变、七处相同。改变包含同股较早选择、较贵的后续入口不再重复选择，以及板块资格不足时凭独立价格事实由未决转为选择。合成案例中的可靠多日推进加正常保持可改变旧规则的判断；孤立急涨、失守、板块资格不足、合法信息型早确认等反例仍按各自证据处理。真实点未出现单凭“保持”新增选择，不能把语义演示说成真实收益证据。
- 结果：只按原公式和截至 2026-09-21 的已发生路径评价可成熟期限。M0/M1 已成熟的 D5 各仅两点；D10、D20 都无成熟入选点。同股同日同入口的已成熟配对只有一点，收益差为零；组均值由不同入选点组成，不能归因为方法改善。较早选择的同股观察点在共同截止日收益较高，但从自身入口计算的盘中最大回撤也更深；另有两法共同错过后续强涨的反例。行动日跳空、参与条件无法由日线核实、交易摩擦与未来效果均保留为限制，逐点原值和计算在私有包。
