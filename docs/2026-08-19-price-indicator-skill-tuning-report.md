# 价格指标本地补全与 Skill 修正报告

## 结论

这次修正了上一轮最关键的逻辑错误：上一轮只检验“某一指标家族能否作为全市场、线性、独立预测因子”，却把“不适合这种用法”扩大成了“不能参与选股”。这两个结论不是一回事。

现在的结论是：

- 本地公式可靠，常用指标不需要依赖 API 批量提供；
- MACD、RSI、K/D、ADX 等可以参加候选发现和比较，但必须放进趋势、路径和市场/板块归因中使用；
- K/D 金叉、RSI 超买超卖、BOLL 触轨等单一现象没有选股权；
- BOLL 的预设正面突破组合在本地样本中没有得到支持，因此只保留波动状态和风险解释用途；
- 长周期突破与路径、相对强弱、量价共同出现时值得发现，但它同时伴随明显回撤和回吐，不能只报“命中”。

## 本地补全了什么

`src/stock_analyzer/analysis/price_indicator_features.py` 统一从本地 `raw OHLC * adj_factor` 计算，不把外部供应商指标存成新的事实源。当前公式版本是 `price-indicator-conditional-states-v2`，包含：

- 趋势：EMA20 距离、MACD 12/26/9 DIF、DEA、柱体、柱体/价格、近 5 日变化和近期交叉；
- 路径：ER20；
- 趋势强度和方向：ADX14、`+DI`、`-DI`、方向差；
- 振荡：RSI14、K/D 9/3、K-D 差和近期交叉；
- 波动：BOLL 20/2 `%B`、带宽和近 5 日带宽变化；
- 长周期位置：距离不含当日的此前 250 日高点及是否突破；
- 量价：20 日方向性成交额平衡和价量推进效率。

新增状态字段的意义不是多报几个数，而是解决旧字段无法回答的问题：MACD 当前为正不等于仍在增强；ADX 高不说明方向；K 和 D 两个静态数不能说明近期是否交叉；BOLL 当前带宽不能说明正在收缩还是扩张。

本地原有冻结样本仍保留在 Git 忽略目录 `local_archive/price_indicator_validation/2026-08-19-price-indicator-validation-v1/`：839,594 条形成日—股票观察、194 个形成日、4,675 只股票。新状态字段可按形成日从本地行情确定性重算，不新增数据库 schema。

## API 核对结果

API 只用于回答“公式是否算对”，不用于替代本地复权计算。

### Tushare

- 仓库凭据可读取基础数据，但直接调用 `stk_factor` 和 `stk_factor_pro` 均返回无接口权限；这被记录为权限失败，没有伪装成已取得数据。
- Tushare 官方 `stk_factor` 文档公开了浦发银行 2022-05-05 至 2022-05-20 的 12 个交易日样例。本地用当时可见行情重算 MACD、K、D、J，共 48 个公开值；四舍五入到文档的 3 位小数后 48/48 完全一致。
- Tushare 专业接口文档确认 BOLL 20/2、KDJ 9/3/3、MACD 12/26/9、DMI 14/6 和 RSI 6/12/24 等供应商参数。RSI14 与其公开 RSI 参数不相同，不能强行对值。

参考：[Tushare 股票技术因子](https://tushare.pro/document/2?doc_id=296)、[Tushare 股票技术面因子专业版](https://tushare.pro/document/2?doc_id=328)。

### TradingView

固定读取 2026-08-18 的上一根完整日线，抽取浦发银行、平安银行、迈为股份、沃华医药和东湖高新，覆盖沪市、深市、创业板及两个当日复权因子变化样本。

- 在相同的未复权价格口径下，本地 EMA20、RSI14、MACD DIF/信号线、BOLL 上下轨、ADX 共 35 个指标值，与 TradingView 扫描接口一致到浮点误差；5 个收盘价也一致。
- 在本地生产使用的复权口径下，遇到现金分红等复权变化，结果会与 TradingView 默认未复权指标不同。这正说明生产计算必须坚持本地复权价，不能为了对齐供应商把除权缺口重新当成真实下跌。
- TradingView 的 `Stoch.K/D` 默认参数与本地 KDJ 9/3/3 不同，因此标为不可比；没有为了看起来一致而改变本地参数。

### 同花顺 / AKShare

已检查 AKShare 暴露的同花顺技术选股接口。公开接口提供“创新高、连续上涨”等当前榜单，不提供可指定历史日期、复权口径和 MACD/RSI/KDJ 参数的逐股数值，因此不适合作为这次公式核对基准。它可用于发现供应商当前榜单，但不能证明本地指标公式正确，也不能安全回放形成日。

## 条件化检验怎样做

上一轮固定线性模型仍保留，因为它真实回答了“指标家族能否在全市场提供普遍线性增量”；但这次不再拿它回答指标的条件用途。

本次沿用同一冻结样本：

- 开发期：2022-07-26 至 2024-12-31，510,901 条；
- 时间后移期：2025-01-02 至 2026-07-21，328,693 条；
- 时间后移期全样本 D1—D20 最高价达到行动日开盘价 +20% 的比例为 17.12%；
- 分组界限只在开发期确定，再原样用于时间后移期。开发期分位数只用于研究分组，不写成生产阈值；
- 比较同时报告样本数、命中、MFE、MAE、20 日末收益、2025/2026 方向和按形成日聚类的 bootstrap 区间。

这不是证明某个指标“导致上涨”，而是检验同一个指标现象在不同语境中是否代表不同事情。

风险不能省略：

- 高 RSI 强路径组的中位 MFE 为 +9.79%，中位 MAE 为 -8.49%，20 日末中位收益为 -1.54%；说明更容易在途中冲高，也更容易回撤和回吐。
- MACD 顺畅组中位 MFE 为 +9.24%，MAE 为 -7.62%，20 日末中位收益为 -0.91%。

- BOLL 结果没有支持原假设，因此不继续换窗口、换阈值寻找好看版本。

## 价格 Skill 怎么改了

`.agents/skills/analyzing-price-trading/SKILL.md` 不再用“六类指标没有全局线性增量”禁止它们参与，而改成一套真实判断顺序：

1. 先扣除市场普涨、板块共同变化和同类同步变化；
2. 用 EMA/MACD 判断趋势方向与加速度；
3. 用 ER 和带方向的 ADX/DMI 判断路径是否连续、趋势究竟向上还是向下；
4. 在趋势语境中解释 RSI 和 K/D，不机械超买卖出、超卖抄底；
5. 用 BOLL 描述收缩/扩张和失败突破风险，不作为正面方向信号；
6. 用 250 日位置与量价共同判断发现价值、剩余空间和透支；
7. 最后仍要回到公司因果、板块比较、流动性和行动日可参与性。

对发现阶段的约束也改了：价格 Skill 可以用“相对强 + 趋势增强 + 路径连续 + 量价支持”或“长周期突破 + 条件确认”等组合独立提交股票；但不得先按某个指标榜单缩成主要候选池。每次必须明确是哪一项技术信息改变了什么判断，并给出最强反证。

## 验证与限制

- 公式单元测试覆盖手算、复权拆分、未来行不变、暖机、重复业务键、新增趋势方向、状态变化和近期交叉。
- 条件结果在 2025 和 2026 分段中方向总体一致；低 RSI 和长突破透支比较的不确定性仍大，Skill 没把它们写成硬结论。
- 历史样本已被过去研究接触，只能称为时间后移但已暴露的探索验证，不是未来收益证明。
- 早期样本缺少完整时点行业比较，所以实际每日研究仍必须调用板块 Skill 做当时的行业/同类归因。
- 本轮没有重新选股，没有修改正式选股逻辑、其他 Skill、数据库 schema 或 `opportunity_type`。
