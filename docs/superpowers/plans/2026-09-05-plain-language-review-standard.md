# 复盘"说人话"标准优化方案（Plain-Language Review Standard）

> **执行提示：** 在不改变程序行为、快照结构、record 校验和既有复盘方法的前提下，把"说人话"固化为可执行、可验收、可回退的写作合同。目标：公开正文的每一句话，不懂股票的用户都能一次听懂；同时不降低可追溯性。不做：不加新模型调用、不加子智能体流程、不改字数区间与检查日安排、不动其他 Skill、不改程序代码。
>
> **审查状态：** 通过（以审查修订版为准）。2026-09-05，GLM-5.3-Flash（最高思考强度指令）独立审查，全部修订已并入本文件：SKILL 段落只替换开头三句、文风基准插入点定于"数值口径与证据核对"末尾并加"本节只定文风"声明、自检第三条改为"支撑数字"、验收演示只在回复中展示、回退简化为 checkout 三个文件。

## 1. 根因（为什么之前改不好）

1. 新合同的写作总标准只有"可追溯"一条，生成被拉向"对账体"（数字当句子主语、术语不解释）。
2. 旧规则里有"术语首现用普通中文解释"，但没有与可追溯标准的优先级关系，也没有范文和自检，执行时被丢掉。
3. 规则描述风格的效果远弱于范文示范；且生成后没有可读性检查环节。

## 2. 四项改动（全部落在两个规则文件 + 一个测试）

### 2.1 双层写法标准（monitor prompt + 复盘 Skill 同步）

把现有"写作总标准"替换为两条并列、冲突时人话优先：

> **写作总标准（两条并列；两者冲突时，说人话优先）：**
> 1. **可追溯**：每个关键判断都有可追溯依据，并解释它支持什么、还不能证明什么。
> 2. **说人话**：先说人话，再给依据。正文每句只说一件事；数字写在括号里当证据，不当句子主语；价格术语第一次出现必须跟一句白话解释（如"上影线——盘中冲高后被卖回来的那一段"）。
>
> 说人话不降低可追溯：每个关键数字仍必须在保存前核对来源，只是从正文主语降级为括号证据。正式事实（停牌、订单取消等）不需要凑数字。

### 2.2 金范文钉进合同（monitor prompt 新增"文风基准"节）

在写作总标准之后新增：

> ### 文风基准（照此行文，不照抄内容）
>
> 以下段落的**事实是示例**，写复盘时必须替换为当天该股票的真实数据；要模仿的只是句子结构、解释习惯和语气：
>
> （四段范文：半山腰歇脚文本，见本文档第 4 节）

### 2.3 术语解释与人话优先绑定（复盘 Skill）

既有规则"必须使用'突破''回撤''上影'等价格词时，第一次用普通中文说明其含义"保留，并在其后注明："本条与可追溯要求冲突时，按'说人话优先'处理；文风以 `ops/forward-monitor-prompt.md` 的'文风基准'为准。"

### 2.4 保存前"翻译自检"（monitor prompt 核对清单追加三条）

在既有"保存前由同一执行者对照来源核对一次"清单后追加：

- 每句话读给不懂股票的人，能否一次听懂；听不懂的那句重写，不是加注释；
- 价格术语第一次出现处，是否都有白话解释；
- 数字是否都已退到括号或核对说明里，正文句子主语是否仍是"发生了什么/意味着什么"。

### 2.5 测试钉住（防止标准被静默删除）

`tests/test_forward_monitor_prompt.py` 新增一个测试：断言 monitor prompt 包含"先说人话，再给依据""文风基准""像爬了一段坡之后在半山腰歇脚"；复盘 Skill 包含"先说人话，再给依据""人话优先"。

## 3. 金范文全文（写入 monitor prompt 的内容）

> 推荐满十天，先说结论：当初赌它"不跟大盘走、自己独立上涨"，目前看赌对了——这十天它涨了7.1%，大盘同期反而跌了0.7%（多出来的约7.8个百分点，就是"独立"两个字的直接证据）。
>
> 但最近三天它基本停在原地，在7.65—7.70元之间小幅晃，成交量缩到平时的一半左右，像爬了一段坡之后在半山腰歇脚。歇脚本身不是坏事——危险的信号是"越跌越有人急着卖"（放量下跌），这种形态没有出现。
>
> 当初最担心的是"这轮上涨撑不了几天"，现在十天过去了还在高位，这个担心解除了一半；另一半没解除：公司这十天没有任何新消息，我们说不清买它的人到底图什么，只能继续盯着。
>
> 离目标还有多远？推荐时定的小目标是20个交易日涨20%，现在时间过了一半，涨幅走了三分之一多一点。要追上进度，接下来得看到成交量重新放大——如果它连续几天放量往上、或者反过来放量往下破位，判断都会变；不变的情况就是继续这样缩量晃。
