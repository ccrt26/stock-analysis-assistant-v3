# 股票分析助手 V3 第二轮知识直接补充精简设计

> **日期：** 2026-07-15  
> **状态：** 待用户书面审核  
> **当前状态权威：** 本文只定义知识补充，不证明生产能力或激活状态；生产状态仍只以 `docs/operations/production-capability-matrix.md` 为准。  
> **替代关系：** 本文替代旧第二轮补充设计和 `2026-07-15-v3-second-round-knowledge-expansion.md` 实施计划中的补充部分；旧文档不得继续执行。

## 1. 唯一目标

在不改变现有数据底座的前提下，核对此前已经明确的高质量候选知识，并补足十三项本地验证淘汰九项后留下的必要分析能力。

每项候选最终只有两个结果：

- `use`：来源可靠，核心理论能由当前数据或当前正式事实直接执行，允许写入可调用知识库；
- `discard`：来源、核心变量、当前可执行性或本地历史方向存在关键问题，不进入可调用知识库。

不设置“有限使用”“暂缓入库”“先作方法参考”等中间状态。候选来源级别高，不等于候选知识自动通过。

本阶段不修改数据底座，不新增连续数据源，不开发因子引擎，不设计评分、权重、推荐、仓位、正式报告、自动任务或部署。

## 2. 已确认的前置事实

十三项旧知识已经完成直接验证：四项 `use`、九项 `discard`。

继续保留并可作为本轮已有基础的四项知识是：

1. Dechow、Ge、Schrand（2010）：盈余质量必须按用途进行多维核对，不能压成一个质量分数；
2. Fama、Fisher、Jensen、Roll（1969）：事件时间与市场调整的基本方法；
3. Brown、Warner（1985）：日收益事件研究的适用条件和统计风险；
4. MacKinlay（1997）：事件研究的正常收益、事件窗口和重叠事件边界。

以下九项结论已被当前 A 股本地历史或当前数据能力否定，不得在本轮换名复活：

- Fama、French（1992）的规模和账面市值比收益关系；
- Liu、Stambaugh、Yuan（2019）的 A 股规模、价值和盈利市值比收益关系；
- Jegadeesh、Titman（1993）的海外个股赢家延续关系；
- Ball、Brown（1968）的非预期盈余关系；
- Sloan（1996）的应计与现金流持续性次序；
- Piotroski（2000）的多项财务改善区分后续赢家关系；
- Novy-Marx（2013）的毛利能力收益关系；
- Bernard、Thomas（1989）的标准化非预期盈余漂移关系；
- Chan（2003）的完整公开新闻与无新闻价格冲击关系。

“不得复活”针对知识主张，而不是禁止阅读同一来源。只有来源中与已淘汰主张明确不同、能够完整保留原意的新命题，才可以作为独立候选重新验证；不得通过删掉关键条件把失败理论改写成容易通过的口号。

## 3. 补充范围不是九项机械替换

九项淘汰不要求寻找九篇同名论文逐项替换。补充的是实际分析能力：

| 淘汰后留下的能力问题 | 本轮处理 |
|---|---|
| 市场共同状态如何改变证据要求 | 验证市场共同成分方法，但不恢复规模、价值收益结论 |
| 行业共同趋势是否真实存在 | 验证行业相对强弱和共同成分；数据历史不足或方向混乱即淘汰 |
| 个股是延续、反转还是没有清晰结构 | 只验证现有 A 股交易制度研究；海外个股动量不再进入候选 |
| 盈利和财务改善是否有质量 | 以已保留的多维盈余质量知识为基础，验证现金支持盈利的独立命题 |
| 业绩披露和公告如何解释 | 使用正式披露层级和已保留的事件研究方法，不再声称公告后必然漂移 |
| 估值如何参与判断 | 在没有新的本地证据前只陈述估值事实和可比性，不建立“低估值后续更好”的知识 |
| 日线流动性是否与后续结果有关 | 完整验证候选论文的核心关系，不能只保留公式名称而删掉失败方向 |
| 波动和极端上涨是否构成风险反证 | 完整验证波动或 MAX 的核心关系，不复制海外阈值 |
| 五只候选是否来自同一风险来源 | 验证简单分散、集中度和相关性方法，不计算最优仓位 |

如果一项能力已经由四项保留知识、正式规则或事实比较充分覆盖，不为了增加数量再找一篇相似论文。

## 4. 冻结候选来源

### 4.1 学术候选

以下是此前已经明确的高等级学术候选。本设计保持候选范围，但不预先保证入库：

| 候选来源 | 只允许验证的核心用途 | 预先边界 |
|---|---|---|
| Fama & French（1993），JFE，DOI `10.1016/0304-405X(93)90023-5` | 市场或共同成分的分解方法 | 不得恢复已淘汰的规模、价值预期收益关系 |
| Moskowitz & Grinblatt（1999），JF，DOI `10.1111/0022-1082.00146` | 行业共同成分与个股自身表现的区分 | 必须用当前 A 股行业数据直接验证 |
| Ma、Liao、Jiang（2024），JEF，DOI `10.1016/j.jempfin.2023.101458` | A 股因子收益的阶段性延续 | 不能把因子组合直接等同于申万行业或热点板块 |
| Zhang、Zhu（2024），IREF，DOI `10.1016/j.iref.2024.103653` | T+1 制度条件下的 A 股短期反转 | 必须分别保持形成期、持有期和制度条件 |
| 张瑞琦、张兵（2025），《中央财经大学学报》，原始出版页 `https://xbbjb.cufe.edu.cn/EN/Y2025/V0/I1/59` | 涨跌幅限制与日度动量、隔夜和日内路径 | 涨停事实不能外推后续上涨，也不能识别交易者身份 |
| Ball、Gerakos、Linnainmaa、Nikolaev（2016），JFE，DOI `10.1016/j.jfineco.2016.03.002` | 经营现金流、应计和经营盈利能力之间的完整关系 | 不能退化成“现金流为正就是好公司” |
| Amihud（2002），JFM，DOI `10.1016/S1386-4181(01)00024-6` | 日收益相对成交额的非流动性度量及论文主张的关系 | 日线代理不是订单簿冲击，也不能识别交易者身份 |
| Ang、Hodrick、Xing、Zhang（2006），JF，DOI `10.1111/j.1540-6261.2006.00836.x` | 个股波动与后续收益横截面关系 | 海外方向和阈值必须本地验证 |
| Bali、Cakici、Whitelaw（2011），JFE，DOI `10.1016/j.jfineco.2010.08.014` | 近期最大单日收益与后续收益关系 | MAX 不能未经验证直接成为负分 |
| Markowitz（1952），JF，DOI `10.1111/j.1540-6261.1952.tb01525.x` | 组合共同风险、协方差和分散的理论关系 | 不输出仓位，不假装它是经验选股因子 |
| DeMiguel、Garlappi、Uppal（2009），RFS，DOI `10.1093/rfs/hhm075` | 复杂优化相对简单分散的估计误差边界 | 不开发优化器 |
| Harvey、Liu、Zhu（2016），RFS，DOI `10.1093/rfs/hhv059` | 防止因子挖掘和事后挑结果 | 只作为研究执行边界，不参与逐股结论 |
| Hou、Xue、Zhang（2020），RFS，DOI `10.1093/rfs/hhy131` | 复现、微盘股和交易摩擦审计 | 只作为研究执行边界，不参与逐股结论 |

Jegadeesh、Titman（1993）、Liu、Stambaugh、Yuan（2019）和 Piotroski（2000）虽然曾出现在旧补充白名单中，但其对应知识已经由本地验证判定为 `discard`，本轮不再作为入库候选，也不重复运行相同检验。

候选文献必须从 DOI 或期刊原始出版页核对题名、作者、期刊、研究设计、核心变量和限制。无法核对原始出处时直接淘汰，不以搜索摘要、券商手册、量化平台文章或自媒体替代。

### 4.2 正式规则候选

保留此前已确认的四个上交所正式来源：

1. 2026 年股票上市规则：业绩预告、业绩快报、定期报告、修正和公司正式披露边界；
2. 2023 年融资融券交易实施细则的当前官方版本：融资、融券及账户合同含义；
3. 2025 年股票质押式回购规则：质押融资、履约和条件性风险；
4. 2025 年回购股份指引：方案、报告书、实施进展、完成或终止的阶段差异。

同时复用现有证监会和交易所关于减持、股份变动和信息披露的正式规则，形成以下候选知识：

- 解禁资格不等于已经卖出；
- 只有正式披露的股东变动才能写成已发生的持股变化；
- 回购方案、计划金额、实际实施金额和完成状态是不同事实；
- 质押本身不是爆仓或减持，只有出现相应条件和正式事实才可升级风险；
- 公司与热点的业务联系必须来自主营构成、公司资料或正式公告，不能因名称相似建立联系；
- 融资余额变化不能识别具体账户身份，更不能写成“机构买入”。

正式规则知识不承担预测收益的任务。它的通过条件是：官方当前版本可以核对，规则原意完整，当前数据字段能够在分析时执行相应事实区分。

## 5. 四类候选采用不同但同样直接的论证

所有候选仍只有 `use/discard`，但不能用同一种历史收益检查错误裁判不同性质的知识。

### 5.1 经验关系知识

适用于行业趋势、现金支持盈利、流动性、波动和 MAX 等论文主张。

每项必须：

1. 提炼完整核心理论，保留研究对象、变量、方向、时间关系和必要条件；
2. 用当前数据直接构造核心变量，不能用名字相似的字段代替；
3. 观察总体方向、较早和较晚时期、关系形态以及决定性反证；
4. 不设置固定收益、胜率、显著性或“十至三十日涨百分之二十”的机械门槛；
5. 当前历史总体说得通、前后时期基本一致且没有决定性反证，才判定 `use`。

如果论文包含测量公式和未来收益关系，不能在未来收益关系失败后只把公式名称留下并声称整项知识通过。只有论文中本来就独立成立、且确实服务当前分析的问题，才可以拆成独立知识候选。

### 5.2 市场状态和价格结构方法

适用于市场共同成分、A 股短期反转、涨跌停路径等方法。

验证重点是方法能否稳定地区分市场共同变化、行业共同变化和个股自身变化，以及原文主张的延续或反转方向是否在当前历史中说得通。方法能做分解但预测方向不成立时，只能将“分解”作为独立命题判断，不能保留失败的预测主张。

### 5.3 正式规则和事实语义

不强行检验未来收益。逐项核对：

- 当前官方原文与版本；
- 规则所区分的事实阶段；
- 当前仓库对应的数据集和关键字段；
- 分析语言允许说什么、禁止说什么。

缺少核心事实字段、官方版本无法核实或规则含义不能直接执行，判定 `discard`。

### 5.4 组合和研究执行边界

Markowitz 与 DeMiguel 的候选知识通过实际候选收益历史验证相关性、协方差、行业集中和简单分散检查能否复算；不要求它们预测个股上涨，也不开发最优权重。

Harvey、Liu、Zhu 与 Hou、Xue、Zhang 通过代码和结果检查验证其边界确实被执行，例如不得事后挑选较好窗口、不得由微盘股单独驱动结论、必须展示反证。它们不进入逐股知识选择。

## 6. 当前数据准入

只允许使用已经验收的数据底座及派生特征，包括：

- 个股、指数和行业日线、复权、涨跌停、日度估值和成交；
- 财务三表、财务指标、业绩预告、快报和定期报告；
- 正式公告、主营构成、公司资料；
- 融资融券、质押、回购、股份解禁和已披露股东交易；
- 已验收的市场、板块和个股交易观察。

候选知识需要产品价格、库存、产量、行业销量、分析师预测、完整新闻、社交情绪、订单簿、逐笔委托或账户身份时，直接 `discard`。本轮不得借此修改数据底座或新接数据源。

“数据齐全”不仅指表存在。核心变量、时点、证券范围和必要条件都必须能表达；相似字段不能冒充。

## 7. 入库与淘汰规则

判断单位是“完整知识主张”，不是论文名称或因子类别。

判定 `use` 必须同时满足：

1. 来源达到 S/A 级并已从原始页面核对；
2. 理论提炼没有改变原意；
3. 当前数据或正式事实能够完整执行；
4. 需要历史关系的知识，其总体方向和前后时期基本说得通；
5. 没有足以否定当前分析用途的反证；
6. 能明确回答分析中的一个实际问题，并说明不能回答什么。

任一关键条件不满足即为 `discard`。淘汰项只在简短结果文件中保留原因，不进入活动来源或活动知识登记。来源与知识按同一候选主张共同准入：不存在“先把论文放进活动来源库，以后再看是否能用”的状态。

现有登记中仍处于 `method_only` 的候选也必须在本轮完成二元决策：通过后改成与其用途一致的 `analysis_evidence`、`observation_only` 或 `hard_boundary`；不通过则退出活动知识。不得继续停留在 `method_only`。

新增知识仍遵守以下表达边界：

- API 原始事实、本地明确公式复算观察、大模型分析判断和面向用户的表达必须分开；
- 成交放大、上涨放量和收在高位只能描述交易结果；
- 缺少逐笔、订单簿和账户身份时不得写成机构买入、主力吸筹或主力未出货；
- 第三方“主力净流入”只能作为标明来源和黑箱限制的外部参考，不能成为本轮知识事实；
- `sector-hotspot-v2` 只是板块热度证据，不是最终热点排名。

## 8. 最小实现和允许产物

实施阶段最多新增或修改以下内容：

1. 一份直接补充验证结果 YAML：逐项记录来源、完整核心理论、当前数据、主要证据、主要反证和 `use/discard`；
2. 一个直接验证模块：只放确实需要历史计算的少量函数；
3. 一个必要测试文件：验证核心公式、二元结果、淘汰项不可调用、时点安全和重复运行一致；
4. 现有来源登记、知识登记和迁移状态的必要更新；
5. 如果理论或方法论文不能被现有来源模型诚实表达，允许增加一个最小的研究设计字段，但不得扩建通用研究平台；
6. 本设计文档和一份详细实施计划。

不创建十五问文档、九类矩阵、通用实验运行器、大型历史面板、因子总表、评分器、验收报告或重复的人工审计文档。中间结果只放临时目录，不纳入版本控制。

## 9. 执行顺序和停止条件

执行顺序固定为：

1. 冻结仓库校验值和现有知识状态；
2. 核对所有候选的官方原文或出版页；
3. 先写候选的完整理论和所需数据；
4. 对结构性缺数据、重复已淘汰主张或原文无法核对的候选立即淘汰；
5. 对剩余经验候选编写最小直接计算并运行历史论证；
6. 对正式规则、组合方法和研究边界完成对应的直接执行检查；
7. 写入全部二元结果；
8. 只有 `use` 项进入活动知识库，`discard` 项退出或保持退出；
9. 运行定向测试、全量测试、离线检查和仓库校验值检查；
10. 提交结果，但不接入生产分析。

出现以下情况必须停止对应候选，不得自由扩展范围：

- 需要修改数据底座、派生特征公式或新增数据源；
- 核心变量只能用非等价字段替代；
- 需要降低来源等级或依赖二手摘要；
- 为了得到通过结果而更换窗口、阈值或子样本；
- 需要创建通用因子框架、评分体系或生产接线；
- 验证代码失败。代码失败必须修复，不能记为知识淘汰。

## 10. 验收标准

本阶段完成必须同时满足：

- 所有冻结候选都有 `use` 或 `discard`；
- 此前九项淘汰知识没有被重新激活；
- 每项 `use` 都能从当前数据或当前正式事实直接执行；
- 每项经验 `use` 的本地证据与核心理论方向基本一致，没有用硬门槛误杀理论，也没有用宽松措辞掩盖反证；
- 每项 `discard` 都有简明、可复核的关键原因；
- 活动知识库不存在 `limited`、`method_only` 等规避最终判断的新增候选；
- 相同输入重复执行得到相同结果；
- 研究仓库 SHA-256 不变；
- 定向和全量测试通过；
- 未改变评分、推荐、报告、任务、部署或生产能力状态。

“补充数量”不是验收指标。如果高质量候选无法通过，宁可留下明确缺口，也不降低来源、数据或理论标准。
