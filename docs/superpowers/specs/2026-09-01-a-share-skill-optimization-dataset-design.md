# A 股 Skill 优化样本数据包设计

## 目标

生成一份可提交到 GitHub、可复现核对的研究样本，覆盖行动日 2026-08-20 至 2026-08-31。样本保留所有正式入选记录、当时冻结的选择依据、明确要求记录的复盘信息，以及每个入选事件从行动日起至 2026-08-31 的行情路径。

## 冻结边界

- 起点以用户提供工作簿中的最早 `action_date=2026-08-20` 为准。
- 终点为 `action_date=2026-08-31`，不纳入 `action_date=2026-09-01` 的研究。
- 原始选择理由和复盘合同以当时已冻结的研究 trace、选择日志和 episode 记录为准，不用事后数据改写。
- 事后行情和跟踪结论单独标记为 outcome/review 数据，不与形成日证据混合。

## 交付结构

数据包目录包含：

- `README.md`：边界、口径、字段说明和已知缺口；
- `manifest.json` 与 `checksums.sha256`：文件清单、记录数、生成参数和校验值；
- `data/formal_selections.csv`：29 条正式入选事件；
- `data/research_runs.jsonl`：每次研究的时间边界、市场判断和最终结论；
- `data/candidate_ledger.jsonl`：当时明确进入候选账的股票；
- `data/decision_trace.jsonl`：候选与最终选择实际引用的决策证据；
- `data/review_contracts.jsonl`：催化、传播链、价格确认、剩余路径、反证、未知和行动条件；
- `data/monitor_episodes.jsonl`：截至终点形成的正式研究 episode 快照；
- `data/monitor_reviews.jsonl`：截至 2026-08-31 已形成的跟踪复盘；
- `data/daily_price_volume.csv`：每条正式入选事件从行动日至 2026-08-31 的日线价格成交量；
- `data/market_context.jsonl`、`data/sector_context.jsonl`、`data/price_context.jsonl`：研究形成日使用或可核对的派生上下文切片；
- `A股Skill优化样本_2026-08-20至2026-08-31.xlsx`：面向人工复盘的汇总工作簿。

## 脱敏与仓库约束

- 不复制原始本地归档目录、事实仓、日志或凭据。
- 不写入用户名、主目录、工作树或其他个人绝对路径。
- 仅导出本样本所需的结构化切片；每条记录保留逻辑来源标识和原始时点字段。
- 不修改研究合同、Skill、正式 trace 或任何既有本地产物。

## 验收标准

- 正式入选记录为 29 条，覆盖 28 只不同股票和 8 个行动日。
- 原附件中截至 2026-08-28 的 25 条记录逐条可匹配；新增 2026-08-31 的 4 条记录。
- 每条正式入选事件都有唯一事件键、选择理由、最强反证、最近替代比较和可用的复盘合同字段。
- 行情数据不晚于 2026-08-31，重复入选股票按不同事件保留。
- 所有 JSON/JSONL/CSV 可解析，清单计数与文件实际一致，工作簿无公式错误并通过视觉检查。
- Git 提交只包含数据包、生成/验证工具、测试和说明；分支推送到 `origin`，不改 `main`。
