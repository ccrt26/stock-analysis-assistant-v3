V3 Phase 3 Strategy V2 架构说明页

本页不是每日股票报告，而是 Phase 3 分析框架地图。它说明每日推荐和重点股票分析如何使用本地知识库、数据、规则和 LLM。后续优化时，用它判断哪些知识已使用、哪些还没用、缺什么数据、哪些知识应该补数据、降级或删除。

一、总原则

知识库先行
先用本地知识库和结构化数据生成证据，再让 LLM 表达。
报告只给结果
日报和重点报告不堆知识引用，只展示结论、理由、风险、操作建议和失效条件。
YAML + HTML 管知识映射
src/stock_analyzer/knowledge/strategy_v2_map.yaml 是机器可读源；本页保留人工可读表格。
交易日必产出
只要是交易日，就要出每日推荐和重点股票跟踪；数据不足也要明确说明。

二、每日推荐流程

1. 本地海选
使用本地行情、技术、量价、估值、流动性、市场和板块数据宽筛。
2. 硬约束过滤
官方 S 级规则剔除 ST、退市、停复牌、重大监管等风险。
3. 机会证据卡
解释发生了什么、为什么、代表什么、风险是什么。
4. 进度跟踪
记录观察第几天、最近 5 天达标几天、离重点观察还差什么。
5. 输出日报
最多 10 只，不显示总分，显示等级和原因。

三、重点股票分析流程

1. 进入理由
形成 2-8 周上行假设，冻结进入证据。
2. 六模块分析
公司业务、基本面估值、市场板块、趋势量价、事件催化、风险反证。
3. 每日跟踪
区分 1-5 日短期信号和 2-8 周中期逻辑。
4. 操作建议
给明确动作、仓位区间、理由、条件和失效点。
5. 复盘优化
5/20/40 日验证结论、建议、知识规则和数据缺口。

四、六模块与知识库用途

模块 回答的问题 主要知识类型 输出给报告的结果
公司与业务 它是谁，靠什么赚钱，概念是否有真实业务支撑。 财报、披露、业务画像、概念映射、会计信息含量。 公司画像、业务支撑强弱、概念可信度。
基本面与估值 业绩、财务质量、估值是否支持 2-8 周上行假设。 盈利质量、Piotroski、价值/规模/盈利能力、估值框架。 基本面支撑、估值压力、数据缺口。
市场与板块 大盘、风格、行业、概念是否配合。 市场因子、行业轮动、宏观金融、风险偏好、政策不确定性。 市场/板块支持、中性或反证。
趋势与量价 走势是否接近可行动机会，是否过热或假突破。 动量、反转、技术分析统计框架、量价关系、涨跌停研究。 突破、回踩、追高风险、技术失效位。
事件与催化 公告、政策、行业新闻、概念发酵是否可能驱动行情。 事件研究、信息披露、公告后漂移、政策和新闻反应。 催化强/中/弱、是否已反映、后续观察点。
风险与反证 什么会证明判断错了，风险是否大于机会。 官方风险、流动性风险、尾部风险、过拟合、数据窥探、行为金融。 主要风险、反向信号、失效条件。

六、未用知识的处理规则

  • 如果知识重要但缺数据，先补数据源，不直接丢弃。
  • 如果知识是核心必需项，缺数据会影响分析结论，必须进入数据补齐计划。
  • 如果知识只是增强项，缺数据时可以暂缓，但要说明原因。
  • 如果知识长期无法验证、也不影响核心分析，应列为删除或降级候选。
  • 知识不能因为“看起来高级”就塞进分析；必须服务每日推荐、重点分析、风险反证、操作建议或复盘优化。

七、LLM 介入位置

阶段 LLM 是否参与 边界
数据采集和清洗 否 只用结构化代码和数据源。
因子计算和规则命中 否 由本地计算和知识规则完成。
证据包生成 有限 可整理结构，不可新增事实。
报告表达 是 把证据讲成人话：发生什么、为什么、代表什么、怎么操作、哪里失效。
推荐和仓位决策 不能独立决定 必须由证据包、规则、持仓状态和风险边界支撑。
