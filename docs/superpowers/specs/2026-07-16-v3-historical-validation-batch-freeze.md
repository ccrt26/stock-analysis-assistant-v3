# 股票分析助手 V3：第一批历史框架验证形成日冻结

> **冻结时间：** 2026-07-16，在本批未来结果查询之前。
>
> **用途：** 预先固定历史形成日、样本边界和数据可得性限制，防止看到结果后挑选有利日期。

## 1. 冻结形成日

从受控主题已经具备约 20 个交易日历史、且截至 2026-07-15 能完整观察未来 30 个交易日的区间内，按上交所开市日从 2025-08-15 起每隔 20 个交易日取一个形成日：

1. 2025-08-15
2. 2025-09-12
3. 2025-10-20
4. 2025-11-17
5. 2025-12-15
6. 2026-01-14
7. 2026-02-11
8. 2026-03-19
9. 2026-04-17
10. 2026-05-20

日期选择不依据形成日后的股票表现。20 个交易日间隔用于降低相邻 20/30 日结果窗口的重叠，不代表正式运行以后只能每 20 日选股。

## 2. 冻结的验证对象

本批优先验证：

- 热点优先、业绩优先、价格透明基线与并行发现是否看到不同机会；
- 并行发现是否扩大未来目标股票的覆盖，同时是否显著扩大噪声；
- 十只压缩是否能够优于同日全市场基础发生率；
- 盘中触及、期末收盘和目标前不利路径是否一致；
- 结果是否由单一行业或月份贡献。

本批不验证真实交易收益、仓位、交易成本、夏普比率或自动买卖规则。

## 3. 历史可得性审计及证据降级

在临时仓库调用现有 `run_research_features()` 对 2025-08-15 复算时，严格历史截止查询返回空交易日历。根因已经核对：历史交易日历的 `cal_date` 覆盖 2021-07-14 至 2026-07-15，但这些历史行的 `available_at` 最早为 2026-07-13 15:01（Asia/Shanghai），属于统一回填时间，不是当年市场实际可知时间。现有派生任务按 `available_at` fail-closed，因此拒绝把这些行提供给 2025 年形成日。

该问题同时意味着，本批无法达到主框架第 18.20 节理想的“所有事实严格历史 `available_at`”等级。为继续执行而不修改正式数据底座，本批冻结以下分层口径：

- 交易日历、日线价格、复权因子、指数、日线估值和涨跌停等确定性市场事实，按其业务日期截断；
- 行业和受控主题目录、成员关系按形成日有效的 `valid_from`/`valid_to` 截断；
- 公告、业绩预告、定期财务和修订事实继续按正式 `available_at` 截断；
- 任何在当前底座无法还原历史可得时间的公司事实不得用于形成理由；
- 结果统一称为“按业务日期和公开时间还原的伪样本外回放”，不得称严格 point-in-time 或真实事前回测。

这不是对正式仓库的修复。本批只读运行完成后，是否需要纠正历史市场事实的可得时间合约，应作为独立数据底座任务处理。

## 4. 防止未来信息泄露

在候选形成冻结文件提交以前，禁止查询上述十个形成日之后的股票最高价、最低价、收盘结果、目标触及和回撤。形成文件只允许包含当日及以前的市场、热点、公司、价格、估值、流动性和正式事件证据，不得包含 outcome、future、hit、forward return 等结果字段。

候选和透明探针冻结后再统一揭示未来价格。无论结果好坏，全部冻结日期和全部探针都必须进入最终报告，不删除表现较差的月份。
