# V3 十三项知识直接验证精简设计

## 1. 唯一目标

本阶段只回答一个问题：迁移清单中十三项 `revalidate` 知识，能否用当前研究仓库的数据证明其核心理论在中国 A 股历史中说得通，并直接用于后续股票分析。

每项知识只有两个最终结论：`use`（保留并允许调用）或 `discard`（退出可调用知识）。不设置有限使用、暂缓使用或方法参考。

本阶段不补充新知识，不调整数据底座，不建设研究平台，不接入评分、推荐、报告、自动任务或部署。十三项验证完成后，才单独寻找能够由现有数据执行的高质量新知识。

## 2. 理论提炼不得走样

十三项知识归并为七组计算以避免重复，但最终保持十三行判断。每项提炼必须保留：原文研究对象、核心信息或变量、主张的关系和方向、不可省略的条件与时间关系、原文限制，以及当前数据无法复现的部分。

提炼只删除背景和重复叙述，不得把多变量关系改写成“低估值会涨”等口号，也不得继承海外论文的固定收益幅度、分组阈值或交易结论。

## 3. 如何判断历史趋势与理论一致

本轮属于科学复现：使用不同市场和当前样本，以尽量接近原理论的变量定义检验核心关系。Hou、Xue、Zhang 对金融异象复现的讨论强调保持变量定义、检查小市值驱动和经济量级；McLean、Pontiff 的样本外研究说明原有预测关系在新时期可能衰减。因此不能因原论文级别高就默认其在当前 A 股仍可用。

每项知识查看以下证据：

- **总体方向：** 完整可用历史中的高低组、前后状态或事件差异是否总体沿着原理论方向；
- **时间一致性：** 较早和较晚历史是否基本同向，而非只在一小段时间出现；
- **关系形态：** 原理论若主张有序关系，分组结果是否大致连贯，而非只有一个偶然极端组；
- **驱动来源：** 结果是否主要由极少数日期、极端股票、微小市值股票或单一阶段造成；
- **反证：** 是否存在足以推翻实际用途的相反时期、相反方向或制度冲突；
- **可执行性：** 当前数据是否真正复算核心变量，而非用相似字段替代原理论。

不设置固定样本数、固定收益、固定显著性、固定胜率或未来十至三十日触及百分之二十等机械通过线。均值、分组差异、时间分段、简单区间和样本数量可以展示，只用于帮助看清关系，不负责自动裁决。

核心关系清楚、总体与前后时期基本符合理论、没有决定性反证且当前数据可执行，则为 `use`；趋势混乱、明显相反、主要由异常样本驱动或数据不能表达核心理论，则为 `discard`。

## 4. 七组计算与十三项对账

| 计算组 | 承接的知识方向 |
|---|---|
| A 股规模与估值 | 海外规模价值、中国规模价值、毛利能力中的估值部分 |
| A 股短期反转 | 海外个股动量与 A 股短期反转 |
| A 股共同因子延续 | 海外个股动量中的行业或共同成分 |
| 日收益事件研究 | 经典事件研究、日收益方法和事件研究综述 |
| A 股业绩公告反应 | 盈余信息反应和公告后价格变化 |
| 正式公告与价格冲击 | 有本地正式公告与未匹配本地正式公告的价格冲击差异 |
| 财务改善 | 盈利质量、应计与现金流、财务改善和毛利能力中的财务部分 |

每组可以复用事实读取，但必须回到十三项原知识逐条判断，不能使同组知识自动一起通过。原设计额外加入的涨跌停和海外行业动量不属于这十三项，本轮不验证。

## 5. 最小代码和产物

最终只保留：

1. 一个直接验证模块，包含七个名称清楚的计算函数和一个顺序调用入口；
2. 一个必要测试文件，覆盖十三项对账、七组核心公式、时点不泄漏、复权和重复运行一致性；
3. 一份十三行结果记录，包含核心理论、主要证据、主要反证和 `use/discard`；
4. 对现有迁移表和知识登记表的必要更新。

不保存大型历史面板、通用规格、通用模型、通用样本构建器、多层结果对象、统一实验运行器或重复报告。中间数据只在内存或临时目录存在，结束后不保留。

当前复杂验证代码不继续扩建。实施时删除不再需要的通用抽象和测试，只选择性保留七组计算直接使用且容易理解的少量安全函数。Git 历史保留审计痕迹。

## 6. 数据和执行边界

- 只读当前研究仓库，不改变数据文件、表、分区、接口或派生特征公式；
- 行情使用真实交易日和复权因子；财务与公告使用正式公开时间；未来结果不得进入当日判断变量；
- “未匹配本地正式公告”不得写成“市场没有公开消息”；
- 日线成交和价格不能解释为机构、主力或账户身份；
- 计算失败属于代码问题，必须修复后重跑，不能当成 `discard`；
- 十三项全部完成前不修改生产调用状态。

## 7. 最终验收

- 十三项知识均有 `use` 或 `discard`；
- 每个结论能回到原理论和本地历史证据解释，提炼没有改变原意；
- `use` 项能够由当前数据重新计算；
- `discard` 项退出可调用范围，但保留简短审计记录；
- 相同数据重复执行得到相同证据和结论；
- 研究仓库校验值不变；
- 最终代码没有通用研究平台、评分、推荐、报告或部署接线。

## 8. 方法依据

- Hou, Xue, Zhang, “Replicating Anomalies,” *Review of Financial Studies* 33(5), 2020, DOI: 10.1093/rfs/hhy131。
- McLean, Pontiff, “Does Academic Research Destroy Stock Return Predictability?”, *Journal of Finance* 71(1), 2016, DOI: 10.1111/jofi.12365。
- Harvey, Liu, Zhu, “… and the Cross-Section of Expected Returns,” *Review of Financial Studies* 29(1), 2016, DOI: 10.1093/rfs/hhv059。该文只用于提醒数据挖掘风险，不转化为机械显著性门槛。
