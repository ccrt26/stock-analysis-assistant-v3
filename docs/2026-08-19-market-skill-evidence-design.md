# 市场 Skill 证据化改造设计

## 目标

把市场 Skill 从“说市场强弱”改成“列出可复算事实、说明比较基线、给出候选命题受到的具体影响”。市场视角仍是四个互补视角之一，不产生股票名单、总分、固定状态、Gate、仓位或收益承诺。

本轮只改市场相关的知识、确定性特征、验证工具、测试和 Skill。价格、板块、公司和总控 Skill 的现有未提交修改不在范围内。

## 两个相互独立的等级

### 来源与证明范围

1. **官方制度或定义**：交易规则、指数编制方案、统计口径。只能证明制度、样本范围和字段含义，不能证明未来收益。
2. **A 股同行评审研究**：提供在特定样本、变量和方法下成立的经验关系。窗口、阈值和效应大小不得直接继承。
3. **海外方法来源**：只提供测量或检验方法；未经 A 股本地验证，不得进入方向判断。
4. **本地时点验证**：使用本仓库可回放数据，冻结设计后检验当前公式和目标期。由于历史数据曾被研究，统一标注为“回顾性、设计冻结但样本已暴露”，不称盲测。

### 使用成熟度

- **一级直接参与**：官方事实、制度边界、指数样本含义和可复算描述事实。它们参与事实层，不产生收益方向。
- **二级直接参与**：A 股来源与本地验证都支持、方向在时间切分中稳定、边界清楚的条件关系。它只能改变某类命题的可信度。
- **验证能力**：有合理来源或研究问题，但本地结果不足、数据覆盖不足或尚未验证。只能形成问题、待核条件或未知。
- **禁止能力**：来源不支持、变量不等价、本地结果反向/不稳定，或涉及主体身份、固定收益预测、机械阈值。不得换说法继续使用。

这两个维度不能混用。官方来源再权威，也不能因此升级成二级收益关系；论文发表层级高，也不能替代本地时点验证。

## 必须回答的市场问题

每次只回答与本轮候选有关的问题，并保留原值、基线和缺失原因。

1. **参与程度**：等权收益、中位数、上涨面、新高/新低、涨跌停分布和范围锚定指数是否同向。指数上涨而中位数或上涨面弱，只能称“指数与普通股票分化”，不能称普涨。
2. **成交与价格推进**：总成交相对过去 5/20 日如何；同时期等权收益、上涨面和路径是否推进。成交放大本身不是风险偏好、主力或趋势确认。
3. **分化、波动和集中**：当日横截面收益标准差相对过去 20 日基线、20 日市场实现波动相对 60 日基线、正收益前 20 只贡献占比。分化只指向共同运动减弱和波动风险，不决定涨跌。
4. **风格和行业传播**：沪深 300、中证 500、中证 1000 的相对表现只描述规模风格；行业扩散必须交给板块 Skill，用时点有效行业成员验证。没有完整历史行业覆盖时保持未知。
5. **制度约束**：T+1、涨跌停、停牌和行动日可交易性改变解释和参与条件，不提供方向信号。
6. **宏观与政策**：只使用形成日前官方原文，必须写出传导链和候选暴露；没有公司/行业传导证据时不得把政策方向映射成收益。
7. **候选依赖性**：验证阶段逐只写明候选依赖市场、板块或独立公司变化的程度、所需市场条件、当前影响、最强反证和失效变化。

## 生产事实的最小补充

保留现有等权收益、中位数、上涨面、指数收益、成交额、均线覆盖、新高/新低、分化、实现波动和涨跌停事实，只增加现有语言无法复算的最小字段：

- `scope_anchor_*`：上证综指、深证成指、创业板指的等权指数收益，以及它和全体股票等权收益的差；
- `return_dispersion_20d_average` 与 `return_dispersion_ratio_20d`：当日分化相对过去 20 个完整交易日的基线；
- `realized_volatility_60d_annualized` 与 `realized_volatility_ratio_20d_to_60d`：20 日波动相对 60 日波动；
- `top20_positive_return_contribution_1d`：当日正收益贡献中，涨幅最高 20 只的占比；
- 必需指数与辅助指数分开报告覆盖。默认范围锚定和规模风格指数缺失会限制判断；科创、北证指数缺失只使对应辅助观察未知，不再拖累默认范围的整体覆盖状态。

不增加情绪代理大杂烩、复杂流动性指数、宏观变量库、隐含主体身份或固定市场标签。

## 验证原则

验证单元是形成日。个股标签只能先聚合成当日机会率、市场路径或趋势组合差，再参与检验，不能把几十万只“股票 × 形成日”伪装成几十万个独立市场样本。

冻结样本期、时间切分、阈值来源、公式、目标、覆盖标准、区间和失败处理见 `src/stock_analyzer/knowledge/market_skill_hypotheses.yaml`。未来标签只在该文件写入并哈希后读取。

结论处理：

- 通过来源边界和本地稳定性要求的关系，才升级为二级直接参与；
- 结果不显著、样本不足或变量不等价，保留为验证能力；
- 结果反向、跨期不稳或来源明确反对单指标解释，写成禁止用途；
- 没有任何一种结果可以产生固定市场分数、选股阈值或市场一票否决。

## 知识落地

被实际采用的官方文献和论文写入 `research_registry.yaml`，包含来源、日期、稳定链接/DOI、市场与样本、变量、方法、证明边界和限制。每个市场能力条目同时记录允许用途、禁止用途、前提、反证、数据需求和本地验证引用。

冻结假设写入 `market_skill_hypotheses.yaml`；运行结果写入 `market_skill_validation_results.yaml`；完整中间产物和输入哈希写入 Git 忽略的 `local_archive/market_skill_validation/`。没有进入 Skill 或结论的检索材料不冒充已采用知识，但会在结果报告中记录弃用原因。
