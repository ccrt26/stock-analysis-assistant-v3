# 首次推荐说明忠实表达：实施提示

本方案经本任务唯一独立子智能体审查，按修订版通过，用户随后授权实施。

目标：首次推荐正文准确反映五个 Skill 的最终判断，数字与指标含义有据。总控同时交 pending 和完整稿；现有 writing 改为局部润色，review 聚焦全文忠实核对；只应用明确、唯一且不重叠的修改。原研究与事实一致而文章说错，修文章；需改判断交回总控同步研究与稿。两者任一改变，不复用旧写审；返研名单改变，事实和范文排除名单同步更新。已采用的旧稿按原机制恢复，不宣称新验收。

范围：交接条款、已有流水线、必要指标定义及对应运行说明。保持选股判据、正式 schema/CSV、公式、模型偏好与不可用接替、复盘和公司介绍；不新增 Skill、评分、审批、调度或发布架构，不改历史与网页标签。

验收：相称程序测试覆盖局部替换、稿/判断对应、返研及中断恢复、空名单、原样交付和复盘拼接；现有三只股票固定材料、原时点、隔离完整稿核对主因/证据/比较/风险接受/条件。模型“通过”不代替逐篇人工核对。原研究问题与文章偏离分别报告，未通过不冒称保证，也不自动扩大试验。

实施时的格式处理：若返回全文仅出现未列明的换行差异，程序仍采用从原稿和明确edits生成的正文，保留原有段落，不采用额外换行调整，也不重跑模型；非换行文字有差异仍不采用。原始响应保留。
