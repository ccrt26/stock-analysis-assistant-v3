# 复盘执行纠偏方案与实施计划

## 目标与范围

让任何执行模型遵守昨天已经批准的普通详评四项、节点六项和范文，先核对事实再作判断，逐篇完成实质分析。正确性指事实、时点、口径可靠，推论有据、未知如实保留；不承诺未来预测必然正确或各模型结论相同。

用户进一步明确：主要修复本次没有遵守已有要求的问题，不自由发挥重设分析框架；更好的写作应体现在今日成稿。按此收窄：保留昨日合同、范文、现有三段外层、schema、三路分配、节点及 D20 冻结；撤回先前拟做的报告渲染改造、范文替换和分析方法大幅重写。不增加语义 Gate、评分器、新任务或新产物体系。

## 优化内容

1. 修正复盘默认入口中“最少事实、D20才串完整过程”的过时提示，直接要求读取现行 Skill 和已批准范文，按普通四项、节点六项、简评分别执行。
2. 在复盘 Skill 增补执行与复查要求：写前确定问题和事实，写中独立论证，写后指出四项／六项的实际落位；再连同现有外层检查重复。普通详评结尾是判断层面的下一观察点，节点按原合同保留阶段验证条件，不互套。
3. 总控及两个 Prompt 只补同一执行入口，不另建分析逻辑。范文保留；已存在的来源和推断边界仍约束范文使用，不能把无公告当无风险、开工当利润兑现、量比当持续需求证明。
4. 对今天11篇成稿逐篇核对原推荐、上轮观点、事实定位、结论依据、目标障碍与下一观察点，并横向检查是否只是换数字的同构文章。程序校验不能替代该复查，未运行的模型不宣称已验证。

## 独立审查与范围收窄

已按用户要求启用恰好一个独立上下文子智能体，结果为“通过（以修订版为准）”。它确认目标应约束证据与判断而非仅调格式，并要求必要方向理由及两类条件不能因去重复而丢失、旧档必须保护。随后按用户进一步指示缩减方案：不做新渲染、不替换范文。现有外层仍完整展示方向理由和两个条件，因此无需新旧呈现生效机制。执行保障、来源核对、隔离验证和受控替换沿用审查意见；不再委派或例行复审。
