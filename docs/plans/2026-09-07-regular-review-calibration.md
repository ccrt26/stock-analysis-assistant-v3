# 普通深度复盘校准与标题优化方案

## 目标、验收与边界

将用户已认可的普通详评写法接入每次现有自动任务：标题直接说明当天值得告知的变化及评价，正文围绕此事解释依据、影响、目标余程及下一观察点。保留既有四项／节点六项、三路分配、原范文及外层三栏。新增的是标题与具体改稿对照，不新增 Skill、Agent、定时任务、研究 schema 或语义评分／关键词 Gate。

修改仅限现有复盘 Skill、该 Skill 的一份普通详评校准参考、两个运行 Prompt、普通详评标题的最小显示代码及相称测试。AGENTS.md、Skill 的 UI 元数据、自动任务的模型／时间／项目配置无须修改。已核实当前任务从研究 Prompt 进入复盘 Prompt，再读取复盘 Skill；不把 UI default_prompt 当作定时执行保证。

技术验收与研究质量分开：引用可达、标题提取／展示、正文保真、账本一致可以本轮验证；新对话是否真正按要求分析，须看之后现有自动任务的实际读取、首篇检查与成稿，不能宣称仅保存规则就保证所有模型写对。

## 实施步骤

1. 修改现有 Skill 的普通详评第一项及现有逐篇复查条目，明确标题／开头的告知目的。核对原观察条件时区分完整满足、部分满足、原条件之外出现新证据；不把杭氧的完整触发强套到中钢。轮换无新增明确是例行复查，不制造重大事件。替换或补充相关原句，避免叠加一套检查清单。
2. 在现有 Skill 的 references/regular-review-calibration.md 保存用户批准的杭氧定稿及改稿差异、中钢的反例边界、轮换无增量的使用说明。只用经用户认可的必要范例，不提交本地完整报告或事实仓。原 Prompt 中银龙及 GLM 范文保留，旧范例中“开工补齐经营”“量能证明买盘”“进度正常”等已被纠正的推论明确标注为不可照用。
3. 复盘 Prompt 在普通详评写作入口明确读取校准参考，先拟首篇的真实告知标题，完成正文后实际检查“今天为何单独告知、判断调整是否有据”，在当前任务运行记录中简短说明核对了什么事实、有没有改稿，再继续其余。记录不加到公开股票报告，不另建日志或审批产物。两个 Prompt 接通该引用，并要求正式 Markdown、合并报告、网页从同一正文呈现。
4. 普通详评标题由 AI 手写，存放于现有 current_review 的首个独立段落，格式为“股票名｜具体变化与判断”，随后空行接正文；不添加字段。只对这个明确格式提取标题。监控页与 Prism 详情将该段作为标题显示一次，余下正文原样显示；无此标题的旧档、节点、简评保持原显示。Markdown 原样保留该首段。代码只呈现，不生成标题、不改判断。
5. 为上述标题读取与显示增加必要的行为测试，检查新普通详评标题独立、正文不丢字、不重复，以及旧稿／节点／简评不受影响。运行现有相关 Prompt、record、三路／冻结及两种展示测试，执行 Skill 结构校验。三种情形（完整触发、尚未满足但需改判、轮换无新增）以现有事实与明示的示例作人工内容核对，不伪装成独立模型实测。
6. 今天只给6篇已认可普通详评添加已给出的标题，分析正文逐字保留。先备份当前 JSON／Markdown／合并报告／展示及受保护文件，保存版本基线；临时项目用原 snapshot 和账本通过原 record 后，检查仅6处 current_review 增加标题。安装前比较基线；若他人改动，重新核对。受控替换、更新合并报告及现有 monitor／Prism 页面；失败恢复替换前实际版本。保留 report_conflict，不运行 prepare、不补数、不改18条账本、5篇节点、7篇简评、原推荐、trace、CSV、D20或截止。
7. 检查差异，只提交本轮规则、已批准教学范例、显示代码、测试和本方案；不提交本地数据、报告、备份、日志、凭据、本机路径或用户原有 tmp/。安全同步 GitHub，不覆盖远端变化。

## 新对话验收安排

下一次现有定时任务执行上述校准，并留下真实读取和首篇检查过程；以后运行按同样入口执行。验收观察三类情形：完整触发不能遗漏事先约定，尚未触发不能伪称触发，轮换无新增不能编造重大变化。当日未出现的情形不硬凑股票或改分配。没有实际运行的新对话／其他模型，汇报为尚未实测；本次不增开任务、不追加委派或模型进程。

## 独立方案审查

已由恰好一个独立上下文子智能体完成只读审查，结果为“通过（以修订版为准）”。执行采用以上范围，并落实以下修订：读取上轮正文中的已保存观察条件，不能只读新增标题；普通详评可解释已经发生的条件变化，结尾仍按第四项；当天无普通详评时跳过首篇校准；标题仅在 regular_detail 且首段符合“股票名｜内容”的单行格式时提取；copy 保留原文，两种详情只在显示时分离标题。旧档、节点和简评保持原行为。本次不再委派或例行复审。
