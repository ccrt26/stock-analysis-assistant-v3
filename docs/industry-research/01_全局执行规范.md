# 热点反向穿透法：全局执行规范 V2.0

本文件由四个阶段 Skill 共同读取。用户日常不需要反复打开；出现冲突时，以本文件和当前 `00_研究范围.yaml` 为准。

## 1. 唯一入口与停止纪律

- 每次运行只执行 `00_运行状态.yaml` 的 `current_step`。
- 每次完成后必须更新 `00_运行状态.yaml` 和 `00_下一步操作.md`，角色切换时立即停止。
- 用户只需要读取当前人话报告和 `00_下一步操作.md`；技术文件由下一方读取。
- A、B、C 每个大阶段默认只允许一次定向补查/纠正/补算。仍无法解决时，写未知、缩小范围、阻塞或停止。

## 2. 三类正式文件

每个关键交接必须同时具备：

1. **报告**：给用户和下次 ChatGPT，解释为什么、证据、反证、未知和结论；
2. **交接 YAML/JSON**：给下一方，写对象、字段、公式、条件、频率、review_due；
3. **证据 CSV**：保存来源、published_at、known_at、claim、support_scope、exclusion、等级和冲突。

不得只交 Word，也不得只交 JSON。

## 3. 字段所有权

- `research_id / version / as_of / theme / precise_thesis / final_payer`：ChatGPT创建，Codex校验，不改写。
- `node_id / product / specification / role`：ChatGPT定义，Codex只做本地映射。
- `entity_name / aliases / ts_code`：ChatGPT提供线索，Codex补齐、消歧和去重。
- `evidence_id / claim / support_scope / exclusion / evidence_level`：ChatGPT负责语义。
- `published_at / known_at / valid_from / valid_to / review_due`：ChatGPT提供来源时间，Codex标准化、保存和维护。
- `local_financial_metrics / valuation / price_metrics / input_manifest`：Codex。
- `business_stage / sustainability / expectation_gap / monitoring_contract`：ChatGPT读取Codex结果后确定。
- `monitoring_state / triggered_at / latest_value`：Codex维护。
- 任何资金行动：只属于用户。

## 4. 证据分层

必须区分：身份、能力、认证/试点、供货关系、订单、重复交付、收入、利润和现金。低等级来源可发现线索，不能单独升级关键关系。

- A：监管、交易所、政府、标准组织、客户/供应商正式文件、量化定期报告；
- B：审计经营资料、正式产品与客户类型、官方行业资料；
- C：认证、送样、专利、招聘、项目/环评、调研；
- D：媒体、互动平台、展会、概念表、关键词和传闻。

每条证据必须同时写“能证明什么”和“不能证明什么”。

## 5. 点时、版本和冲突

- 只使用 `available_at/known_at <= as_of` 的事实。
- 每次更新生成新版本，旧版本只读；不得用新结论重写过去。
- 发现冲突新增 conflict，不覆盖对方字段。
- Codex数值变化不自动改变ChatGPT定义的产业/公司状态；达到触发条件后生成触发包。
- 所有未知继续保留，有证据后再补，不得静默删除。

## 6. 缺失状态

以下状态不得混为一谈：`complete`、`partial`、`unsupported`、`query_failed`、`no_record`、`unknown`。缺失不等于零，无记录不等于不存在。

## 7. GitHub与分支

- 安装使用短分支 `feat/industry-research-workflow-v2`。
- 每次研究使用 `research/<topic-slug>-<period>`。
- 研究过程文件只放在 `research/industry-runs/<research_id>/`。
- 不把本地事实仓、Token、密钥、绝对路径或大批原始文档提交 GitHub。
- 重大触发可在原研究分支继续版本化；不需要为每个小步骤新建分支。

## 8. 与现有股票助手的边界

本流程是季度/半年产业研究与中期观察，不替代现有短周期股票研究总控。不得修改现有五个 Skill、数据 schema、定时任务、Forward CSV、D20 口径或价格场景来承载本流程。C阶段形成研究状态后，如用户要进入实际行动判断，仍需另行调用现有市场、板块、公司和价格体系。

## 9. 永久禁止

- 不固定保留公司数量，不按名单补位；
- 不从价格上涨倒推产业关系；
- 不用综合总分补救产品/关系/生意硬门失败；
- 不绕过登录、验证码、反爬和授权；
- 不为“全自动”建设全互联网爬虫和大平台；
- 不自动买卖、决定仓位、止盈止损或承诺收益。
