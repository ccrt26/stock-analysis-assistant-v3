# Selection Lab 审阅包

本目录只包含可公开审阅的预注册清单、聚合状态和验证记录，不含本地事实、完整逐股样本、预测、模型二进制、凭据或个人路径。

当前主结论为 `实验阻塞`：没有机器可读且能够证明在未来揭示前冻结的完整候选链。完整范围轨也因历史证券身份不可回放而关闭。所有不可评价指标使用 `null` 并附 reason code；次级确定性研究面不得升级主结论。

文件分为：

- 预注册：`previously_used_formation_dates.json`、`feature_dictionary.json`、`split_manifest.json`；
- 血缘与能力：`data_lineage_manifest.json`；
- 聚合结果：`baseline_metrics.json`、`ranker_metrics.json`、`opportunity_type_audit.json`；
- 模型与案例：`model_coefficients.json`、`rank_examples.json`；
- 验证证据：`verification.json`。

四个 Skill 的机会类型修改是语义和职责修正，不是已经通过未来收益验证的选股改进。
