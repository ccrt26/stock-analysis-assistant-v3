# 价格指标本地补全与 Skill 修正执行 Prompt

## 目标

沿用本地日线 OHLCV、成交额和复权因子，确定性计算价格研究真正需要的技术信息；抽取少量股票和日期，与可访问的外部 API 对值并说明口径差异；再按“趋势—路径—振荡—波动—量价—长周期位置”的实际判断顺序做条件化检验，修正 `.agents/skills/analyzing-price-trading/SKILL.md`，让有效指标能够参与候选发现、比较、反证或行动日判断。本轮不重新选股。

## 验收

- 本地可以从复权价量计算 MACD/EMA、ER/ADX、RSI/KD、BOLL、长周期高点位置和方向性成交信息；只补实际判断缺少的状态变化，例如趋势方向、交叉或波动扩张，不扩充指标大全。
- 用覆盖不同市场、行情状态和至少一个复权变化场景的小样本，与至少一个能返回同类指标的外部 API 核对；相同公式报告数值误差，公式或初始化不同则明确差异，不能为了对齐改公式。
- 检验指标在明确条件下是否改变判断，而不是只检验它能否作为全市场、线性、独立预测因子：例如强趋势中的高 RSI、下跌趋势中的低 RSI、MACD 变化与路径效率、BOLL 收缩后扩张、突破与量价确认。开发期确定条件，时间后移期核对方向和稳定性，报告实际样本和结果。
- 价格 Skill 写清实际使用顺序、每类指标回答的问题、能参与哪种研究判断、必须搭配的原始事实和反证；不把单个金叉、超买超卖、触轨或固定阈值写成自动选股规则。
- 运行相关单元测试、业务场景验证、完整测试和 Skill 格式校验，保留可复查结果。

## 范围与不做事项

- 只修改完成上述目标必需的本地派生计算、测试、一次性核对/验证脚本与结果说明、价格 Skill。优先复用现有文件和本地冻结样本。
- 外部 API 只查询少量核对样本，不批量下载、不补全指标库、不新建采集系统或数据库 schema，不暴露凭据。
- 不修改总控、市场、板块、公司 Skill，不修改正式选股 Python 逻辑或 `opportunity_type`，不重新选股。
- 不建立评分、权重、Gate、参数搜索、状态机、Agent、CLI 框架或测试框架；不把研究分组阈值直接写成生产硬规则。
- 保留现有工作树、`c568bbd`、`bingo/` 和 `who-is-it/`；不 reset、不删除或改写无关内容，不 commit、不 push。

## 关键约束

- 本地计算只使用形成时点可见数据；API 对值只验证公式，不引入未来行情或未来事实参与研究结论。
- 技术指标都是价量的变换，可以作为条件化证据参与研究，但不能替代市场/板块归因、公司因果、剩余空间和可参与性。
- API 查询失败、接口不提供同参数、初始化或复权口径不同，分别记录为失败、不可比或口径差异；不把未知写成一致。
