# 怎样看懂选股方法复盘

打开现有 WEB 左侧“选股方法复盘”。这里回答“选股的方法要不要改”，每日个股复盘回答“这只股票后来发生了什么”。两者分开，避免涨跌结果和规则修改混成一团。

## 从发现问题到修改规则

1. 先写问题，例如“是不是总等涨了很多才入选？”固定连续5个研究日，所有实际候选都保留。
2. 把原推荐前20个交易日接完整。未满20日、缺行情、没有可靠入口、条件事件分别列出，不拿未知冒充失败或成功。
3. 看完整路径：D5/D10/D20、20日内收盘是否曾涨20%、期间最深下跌、从高点的最大收盘回撤、相对沪深300。触达过20%但随后大跌，也必须看见。
4. AI回查原理由，找支持例、反例、原来的替代股票和其他解释。程序只算数，不自动写原因或改Skill。
5. 写清“原来怎样、现在建议怎样、代价是什么、用什么结果检验”，由你批准后才改规则。
6. 新版本用之后的连续批次验证；记录方法版本、实际首次运行和未决问题。新规则写好了不等于收益提高了。

## 本次改变的白话例子（数字虚构）

某公司公布真正新增的重要订单，第二天已有一个完整交易日，价格、成交和同行响应与订单逻辑一致。旧方法可能仍要等三五天持续上涨；新方法允许此时比较是否值得入选，同时说明消息真假、利润影响、当前入口和失败风险。

如果只是股票忽然上涨，没有可核实新变化，仍要多日确认。看到旧消息、只读标题、拿三只上涨股票冒充全行业，都不能走早确认。

潜在好处是减少反复等待带来的入口抬升；代价是首日假启动可能更多。要比较假启动、下跌和剩余收益，不能只比较是否选得早。已经离低点很远不必然选错；还没涨也不必然值得买。

## 页面上的状态分别是什么意思

- “数据已齐，待人工整批研究”：数据够用了，AI还没据此完成研究。
- “初步诊断”：有可检查的材料，但整批尚未满20日或有缺口，不能声称完整验证。
- “整批研究已完成”：该批已经实际写出结论，不意味着提出的新方法已被未来结果证明。
- “已采用、待新样本验证”：规则已改，效果仍须等待之后的数据。
- “尚未开展”：该时点没有研究报告，不是隐藏结论。

下一批区域提供可复制的研究请求。复制给助手即可启动人工批量研究；现在没有另加一个后台自动调参任务。准备状态只在既有本地页面重新渲染时更新。

## 去哪里核对

每批唯一存储在 `local_archive/skill_optimization/<batch_id>/`：

| 文件 | 能回答什么 |
| --- | --- |
| `source/` | 原轨迹、全部候选、每日路径、固定20日结果、数据限制；由既有导出器生成及校验 |
| `00_问题与范围.md` | 事先想检查什么、包括哪些研究日、能推翻假设的结果 |
| `01_样本对照.csv` | 每个样本的去留和数字；空白是未知或不适用 |
| `02_研究结论与后续验证.md` | AI实际写的原因分析、反例、改动代价和后续验证 |
| `review.json` | 报告可用时间、版本文件引用、状态与变更说明 |

真实材料留本地，不随公开GitHub源码上传。WEB把正文和完整表格内嵌，可展开阅读。最新入口的方法研究使用自己的编写时间，可能晚于个股的历史观点；历史日期HTML只显示当时已经编写的报告，不把今天的认识塞回过去。修订使用新文件和新的实际编写时间。

## 理论依据的边界

信息逐渐传播可能让价格先反应不足、之后延续，也可能被追逐到反应过度。因此我们把“新信息首次响应”和“仅价格连续上涨”分开研究；该理论并未证明本项目在A股一个交易日确认一定优于五日确认。[Hong与Stein（1999），作者页面](https://stein.scholars.harvard.edu/publications/unified-theory-underreaction-momentum-trading-and-overreaction-asset-markets)

反复用已经见过的赢家调条件，会把噪声当成规律。本轮历史案例只能提出和检验解释，真正的改善要在新批次中观察；不会用几只截图调出一个漂亮胜率。[Bailey等，回测过拟合研究](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)
