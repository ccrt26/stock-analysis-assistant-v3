# 市场 Skill 证据化改造实施计划

1. 核验当前 `market_context`、知识库和输出合同，保存本设计与冻结假设的 SHA-256。
2. 只从交易所、指数公司、期刊出版页或作者公开稿核验来源；把实际采用的来源和边界写入知识库。
3. 先给市场特征和验证函数补失败测试，再实现最小字段；公式版本递增且保持未来行不变性。
4. 运行冻结的形成日级历史验证，一次性生成输入清单、阈值、逐形成日结果、区间、时间切分和结论。
5. 将通过、未决和禁止结果写回知识库；然后重写市场 Skill，只引用已落地能力。
6. 运行市场特征、验证器、研究任务、健康检查和知识 YAML 校验，并审查最终差异，确保不触碰价格调优文件。

不做：重跑正式选股、修改总控/价格/板块/公司 Skill、建立市场评分或状态机、连接交易、增加宏观指标库、提交 Git。
