# 不修项目清单

| 项目 | 本轮为什么不修 | 以后如何处理 |
|---|---|---|
| 公司未披露的液冷主题收入、毛利、净利润和现金 | 属于正式披露缺失，不是程序故障；公司总额和混合业务分项不能替代 | 季度/半年财报复核；重大公告触发时由对应产业方向重新判断 |
| 私有客户、精确订单金额和复购金额 | 公开材料没有可靠披露，不能从“批量交付”“核心客户”反推 | 重大事件或正式披露出现后定向核验 |
| 精确良率、有效产能、二供份额和客户自制比例 | 当前只有能力、扩产或定性线索，没有可审计数值 | 对应产业方向提出明确合同且取得授权数据后处理 |
| 全量公告库与全市场爬虫 | 10 份恢复样本已用限定向官方路径解决，未证明需要通用正文系统 | 新方向再次出现相同且可稳定复现的问题时再审计 |
| 招投标平台 | 液冷试点没有证明它是完成当前计算的必要输入 | 对应产业方向确有付款人/项目核验需求时单独授权 |
| 全市场实体图谱、股权图谱或非上市公司大库 | 现有研究级实体映射已正确区分证券主体和母子公司 | 新方向按单个实体轻量映射；跨方向证据足够后再评估 |
| 行业相对收益的非必要扩张 | 当前相对沪深 300 已可用；缺少点时可靠行业基准不阻断产业判断 | 对应方向确有可用基准时按需计算，否则保持 `unsupported` |
| 长期估值历史的非必要扩张 | 260 个交易日实际窗口已经清楚披露，不应为追求“5年/10年”临时建数据 | 现有点时历史自然积累后再扩展 |
| 液冷 D2 日、周、月自动监控 | 本轮是修复前审计，用户未授权启动 D2 | 仅按已批准 D1 合同和用户后续明确授权启动 |
| 现有五个短周期股票研究 Skill | 与季度/半年产业研究分离，当前问题未触及其合同 | 只在对应短周期研究任务中单独审阅 |
| Forward CSV | 当前缺口与未来收益评价文件无关 | 只在正式选股/复盘任务中按原合同处理 |
| D20 口径 | 当前审计未发现 D20 计算问题 | 只在价格研究合同变更时单独审批 |
| 11 个价格场景 | 当前问题是产业计算准备状态，不是价格情景本身 | 价格情景任务另行审批 |
| 现有定时任务 | 本轮不实施监控，不应改变调度 | 仅在用户明确批准自动任务变更后处理 |
| 数据 schema、新数据库表、新依赖 | 所有结论可由现有研究文件、JSON/CSV 和方法文字解决 | 只有未来重复证据证明现有存储无法表达时再单独设计 |
