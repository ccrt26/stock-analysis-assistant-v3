# 五个 Skill 选股逻辑基线诊断

## 诊断边界

本诊断只回答现有逻辑为什么会混入条件事件、弱选、错过同类比较或继续补位。形成日判断只使用各次 selection_as_of 前冻结的市场、板块、公司和价格事实；2026-08-31 以前的行动后路径只放在“早期评价”列，不反写形成日理由，也不作为调整固定阈值的依据。

## 三批最小修改摘要

### 第一批：语义与执行类别

- 修改文件：五个当前 Skill、V4 合同、两个 ops Prompt、forward_selection.py、forward_monitor.py 及现有相关测试。
- 只保留 V4 当前枚举和输出示例，旧格式仅作为历史读取说明。
- 从现有 research_thesis 派生 confirmed active 与 conditional event lead；用户输出和正式推荐数量分开。
- active 仅在有可靠入口时开启 D1—D20；conditional 在条件未观察、未满足或无可靠入口时不使用行动日开盘回算。只记录 met/not_met/unknown，不建设状态机。
- 独立验证：合同/Prompt/selection/monitor 定向测试。
- 不做：数据库表、迁移、新状态、新发动机、自动参与服务。

### 第二批：五个 Skill 的候选比较与停止

- 修改文件：五个 Skill、V4 合同和 ops Prompt；仅在代码可确定行为需要时修改 selection/monitor；修改现有测试；新增 29 行 selection-impact-matrix.csv。
- 市场只改变搜索重点；板块严格分两步；公司先证明事件与兑现再交价格；价格用现有字段区分多日推进、单日脉冲、成交有效和组合余量；总控先同发动机比较，再跨类比较并停止补位。
- 29 条矩阵对旧 V1 标注 legacy_v1_not_rewritten，对 V4 只按形成日证据修订 output class、优先级、行动条件或取舍，早期结果单列。
- 独立验证：五个 Skill 语义、现有 schema、价格场景不变和用户输出测试。
- 不做：新评分器、阈值优化、行业配额、股票专用规则或第二轮调参。

### 第三批：结果反馈数据

- 修改文件：export_skill_optimization_dataset.py、其现有测试；只有工作簿需要展示时才改 workbook；按现有 validator 真实验证。新增 candidate_outcomes.csv 和 conditional_event_outcomes.csv 到新研究目录。
